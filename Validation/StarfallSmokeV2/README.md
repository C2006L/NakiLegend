# Starfall smoke V2

P 星陨的视觉调整：深紫色球体取代五角星，24 个有数量上限的烟团构成每颗球的拖尾及落地烟尘。烟团按技能时间独立扩散、漂移、淡出，全部挂在技能根对象下，房间切换时统一清理。球体与烟团纹理由运行时代码生成并缓存，不依赖额外贴图导入。

保留三个固定落点、预警／伤害时间、资源消耗、冷却与蚀魂印引爆。下落过程有加速感，落地后最多保留 0.5 秒烟尘，不重复造成伤害。

Unity 2022.3.62f3 隔离工程原生运行 **PASS 27 checks**，覆盖原星陨范围伤害、锁定落点、消耗、引爆、防重复伤害及换房取消，以及球体纹理、实际烟团、扩散漂移、撞击后残烟和根对象清理。已检查 `runtime/violet-orbs-descent.png` 与 `runtime/violet-orbs-impact.png`。

`build.py` 使用已有回归测试辅助函数，只运行本次影响的星陨与视觉检查；不修改玩家主工程存档。原生入口 `NakiStarfallSmokeV2Smoke.Run`。
