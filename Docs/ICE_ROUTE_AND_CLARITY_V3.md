# 霜潮路线、地名与蚀魂印修正

## 霜潮群岛

三层仍各有 14 个房间，总计 42 个，原编号保留。房间之间改为明确的主路和支路，移除能从入口两三间直接走到首领的捷径。

| 楼层 | 地区 | 主路顺序 | 首领 |
|---|---|---|---|
| 第 1 层 | 冰港沿岸 | 码头 → 冰封回廊 → 冻潮巷 → 霜甲哨所 → 霜甲巡道 → 渔具仓 → 断桨巡道 → 破霜门廊 → 晶甲庭 | 裂冰甲兽 |
| 第 2 层 | 裂潮冰峡 | 峡口营地 → 裂潮长桥 → 雪壳滩 → 风雪裂隙 → 霜纹执礼者 → 冰峡回廊 → 回声石道 → 护灯队哨所 → 霜镜猎场 | 霜镜巡狩者 |
| 第 3 层 | 寒潮晶庭 | 晶庭前哨 → 潮纹环廊 → 冰晶林 → 冻潮侧殿 → 冰甲禁卫 → 碎霜庭院 → 潮汐穹顶 → 晶纹执礼者 → 守望者前厅 → 寒潮祭庭 | 寒潮守望者 |

首领距该层入口分别为 8、8、9 次过房，每层只有一间首领房。支路放置救援、观测记录、额外战斗或物资，不能绕过主路战斗直接接近首领。

每层保留一个营地、一个奖励箱。营地需要交互领取一次性物资：生命 +2、护盾 +2、元素 +25；反复出入不刷新，也不在进门时自动回满护盾。清场自动存档继续保留，避免测试和更新丢进度。地图小图中的 S 表示层间石阶，并非免费回复站。

第二层每个普通波次由至少五名错峰入场的敌人开始，包含猎犬压进、弓手射击和后排执礼者；后段与精英房进一步增加压力。普通战斗为三波，第三层普通四波，精英逐层三／四／五波。既有援军、掩体与攻击预警继续工作。

绞盘观测站加入实物绞盘、观测簿和具体的冰峡战斗／救援线索；层间前哨加入行路记录。回流闸室在冰石归位前也能检查冻结的绞盘，归位后使用原双绞盘机关。霜镜首领后不再放木质箭头牌，改由出口方向标引导尚未完成的救援。

结尾流程保留：首领 → 取回冰石 → 营救破冰队与修复双绞盘 → 开启回流总闸 → 返回码头点亮归航灯 → CG → 天赋 → 航图。

## 赤炉群岛

楼梯原先漏了火岛判断，错误读取雷岛的“引雷遗址”。现在提示直接读取实际目标房间所属岛屿、楼层和地区；反向楼梯也读取其真实目的地。

黑砂海岸避难所改为靠墙的玄武岩建筑，战斗中居民在建筑内，不再把居民上半身画在独立门板上。清场后才出现救援绞盘，开门后居民在建筑外安全位置出现。工坊石阶口移除无意义的独立门板，保留真正的层间石阶。

## 蚀魂印

O 仍消耗 8 贤者之石能量，冷却 4.5 秒，持续 6 秒。施印立即造成一次 12 基础伤害，并显示“蚀魂印 · 攻击引爆”。之后普通近战、弓弩、法杖或流星命中被标记者均可触发一次 28 基础伤害的短范围爆发，受原技能加成影响。

每次爆发至少间隔 0.6 秒，一枚印最多五次；同一组流星不能连续结算五次。爆发有声音、环形破裂与次数反馈。目标死亡、换房或持续时间结束后清除标记。

## 旧档与试玩

旧 42 房间冰岛存档自动从 `ice-ch3-v1` 迁移到 `ice-ch3-v2`，房间编号、已清理状态、已取奖励、任务、背包和人物资源保留。早期 3／5 房间测试档也能续接。读取后位置使用安全落脚检查，避免新掩体把人物卡住。已经通关的房间保持通关，不会为了展示新布局强迫重打首领。

停止 Unity 播放、等待编译完成后重新运行即可。继续现有档能检查名字、楼梯、救援和蚀魂印；完整的新首领间距在未清理的路线里体验。另起测试会使用现有备份机制，玩家实际存档不因本轮同步被清空。
