# 暮钟岛剧情状态与 CG 分镜

本章把前五岛的救援与前代勇者的经历接在一起。身份先由玩家调查确认，随后当面对质；胜负、战后任务、结局、奖励和航图启程分开推进。以下均为设计规格，只有登岛概念图已生成，完整 CG 与演出尚未制作。

## 三个关键事实

1. 府邸主人曾奉同样的委任出海，也曾修渠、护送和救援。他的转变发生在受封之后，不能把此前善行改成伪装。
2. 骑士体内的暗元素源石与少年右眼的人工容器不同。人工容器能积存战斗残响，也可能被刻入接替命令；暗元素本身不是邪恶意志。
3. 面板暗能是可消费的残响储量；“一人份”指能够承担或中断契约的完整自我。再多点数不能凭空拼出一个人，最终选择不把余额改成 1，也不清空玩家已有能量。

第二层工坊用两种装置展示区别：一侧残响容器驱动空甲，另一侧完整淬炼名册记录了姓名和被注销的身份。医师、钟匠和档案各说明一部分，最终灯室可完整重读规则。不能用一个含糊词到结尾才解释所有设定。

## 主线行动与状态

| 节点 | 玩家实际做什么 | 留下的变化 | 下一目标 |
| --- | --- | --- | --- |
| 登岛 | 下船、阅读关港公告，沿东侧岸路前进 | 渡口被发现、开场只播放一次 | 调查纪念庭与巡守封锁 |
| 卫长战 | 战胜卫长，他缴械并交出旧村通行权 | 战斗房开放、专武可拾取 | 进入旧村，查看粮药困境 |
| 放粮与通药 | 清场后 F 开仓闸，打通药运走廊 | 安全侧门开放，居民实际接运，不站在新战斗里 | 调查淬炼工坊 |
| 身份档案 | 阅读佩剑编号、受封像与委任书 | 身份确认 CG；线索记入手记 | 停下执行旧命令的机关 |
| 掌印机关 | 击破刻印臂与主机 | 契约原令可取得，内庭开门 | 经过旧航海室，抵达最后灯室 |
| 最后灯室 | 整理装备、查看规则、保存独立恢复点；确认进入大厅 | 保留可恢复的战前状态 | 与大骑士交手 |
| 大骑士战 | 凭已有武器、技能与能量击破三阶段 | 明确记录战斗胜利，全部攻击与援军停止 | F 查看破损契约与暗源石 |
| 战后 | 选择自己的处理方式 | 光暗使用不同状态分支 | 完成对应收尾，而不是立即跳旧岛 |

支路的药材箱、家书和停钟操作提供补充，不以集齐三张纸当作开门钥匙。第二层固定档案有主路保障；自由跳岛漏读五岛手记时，在此处补足必需事实。

## 关键对白

### 登岛与旧村

船匠：“灯还亮着。可这一年，从这里寄出去的信，越来越少了。”

关港公告：“为保全居民，未经领主许可，不得离岛。”

洛恩：“仓里有粮。我们缺的，从来不只是粮。”

缇娅：“他以前把自己的口粮留给这里。后来，他开始要求我们证明，自己值得被留下。”

米菈：“我没什么能带走的了。可人总该像风一样，有离开的自由。”

### 工坊与身份

少年：“一遍遍被唤醒的灵魂……是不是连安息都被夺走了？”

伊芙：“空甲里的只是残响。有人把它们叫作归来，好让命令继续下去。”

缇娅：“石头记得力量，不代表它记得一个人。名字、牵挂、愿意作出的选择，不能靠数量拼起来。”

档案配旁白：“同一柄佩剑，同一份王命。受封栏里的名字，属于上一位出海的少年。”

### 最终对质

大骑士：“他这一次，还是让一个孩子出海。”

少年：“你说的是国王？”

大骑士：“我也曾以为，只要把碎片带回去，一切就会结束。”

少年：“那后来呢？”

大骑士：“后来，我以为只要再强一点，就不必再失去任何人。”

短暂停顿，骑士握住重剑，旧蓝披风的内衬露出。

大骑士：“我也曾是屠魔的少年。后来，我披上了魔的铠甲，他们却仍叫我救世主。”

这些话分别回应用户提供的轮回、如风与屠魔台词，不把四句全部堆在终战前。身份已经在档案中确认，此时对白是对质，而不是第一次凭一句话突然揭露。

## 光线战后

1. 留在大厅，F 检查大骑士留下的源石与契约。获得暗碎片的领取状态单独保存。
2. 破坏已经暴露的命令节点。节点可由普通武器或已学技能破坏，再 F 解除连接；光系战技有视觉优势，但不强制要求学过 P。
3. 拆契约后开放返回旧村的安全通路。玩家可自行返回，或在安全出口明确选择“返回避难院”；不自动传送。
4. 回避难院 F 打开最后的离岛门。居民开始准备行李，庄园从“谁也不准离开”转为允许离开。
5. 渡口与船匠 F 告别，播放《归途尚未结束》，之后结算一次岛后天赋；再次交互展开全域航图，由玩家选择目的地。

若已集齐其他五石：少年带风雷冰火木暗六片与证据返乡，等本土章节实装后开放对应入口。若尚未集齐：只说已取得暗石与证据，航图继续指向未完成地区，不能强行跳转本土或假称六片齐备。

主角：“你把自己留在这里，是想替所有人挡住风雨。”

主角：“可他们也得有走出去的路。”

骑士：“那就带着这些回去。别只带回石头。”

大骑士解除契约后的生死可通过气息渐弱、最后松手表达，镜头不使用新敌人突然处决他。具体立绘确认前保持一版统一演出，不把同一人同时放在尸体、说话与存活 NPC 三种状态中。

## 暗线战后

骑士被击破后，接替纹路与少年右眼产生共鸣。战斗胜利保留，进入独立的最终仪式界面。玩家可以先暂时离开、回访或继续其他岛屿；只有主动确认最终仪式才结束冒险。

| 选择 | 确认页明确写出 | 演出与结果 |
| --- | --- | --- |
| 将代价转嫁给居民 | 将对避难院中已救出的无辜居民实施完整淬炼，少年接替大骑士，本次冒险结束 | 居民屋内灯光熄灭，以关门、空屋和名册失去回应表现；新甲胄与命令包住少年 |
| 由自己承担 | 耗尽自己的完整意志阻断接替，少年死亡，本次冒险结束 | 少年把自己的意志投入容器，切断命令，居民生还，播放《一人份的贤者之石》 |
| 暂不执行 | 保留战后进度，允许继续探索与整备 | 关闭界面，保留战前恢复点与当前战后安全点 |

先呈现两种选择与具体代价，再进入单独确认页。新打开确认页时清掉上次 F 输入，松开后才允许再次确认，提供返回按钮，不能长按一次 F 连过两层造成不可逆选择。

少年：“这里还有一人份。”

大骑士：“你知道那意味着什么。”

少年：“这一次，不必再从别人身上取了。”

暗系高储量仍可强力完成 Boss 战，不把死亡归咎于伤害不够。“一人份”通过工坊、医师与灯室逐步交代，不能临时编一个必须用平民灵魂解锁的无敌盾。两种暗线结局都发生在战斗胜利之后，独立于普通败北。

## 五组 CG 分镜

| CG 与触发 | 分镜节奏 | 画面与声音 | 结束后 |
| --- | --- | --- | --- |
| 暮钟不迎归人，首次登岛 | 约 18～24 秒：水面与绳索 → 少年踏上干燥码头 → 空街 → 钟楼与一扇紫光窗 | 海声、木船轻响，单声远钟；不预先露出骑士正脸 | 少年在岸上出生，保留入场存档，明确指向东侧岸路 |
| 画像中的少年，首次读档案 | 约 12～18 秒：旧画中的蓝披风 → 佩剑护手编号 → 画像右眼涂痕 → 当前少年抬眼 | 纸张、短暂音乐停顿，接熟悉航海主题的低音变奏 | 回到安全档案室，可重读记录；不提前放最终对质 |
| 一人份的贤者之石，暗线自我承担 | 约 25～35 秒：右眼余光 → 展开的家书 → 一人剪影投入光中 → 命令纹断开 → 避难屋重新亮灯 | 少年关键两句，紫光渐白，钟摆停下；不展示肢解或血腥提取 | 结局页、手记记录、恢复独立战前点的入口；不自动覆盖它 |
| 新任大骑士，暗线转嫁代价 | 约 25～35 秒：确认对象的避难院 → 门关闭、灯灭 → 旧甲包住少年 → 相似的眼睛 → 下一份委任书 | 不用胜利欢呼；落印声与开场钟声首尾相接 | 结局页与战前恢复入口；不按普通通关返回王国 |
| 归途尚未结束，光线离岛告别 | 约 25～35 秒：村路重新放行 → 米菈抱种盒登船 → 六片或实际已得碎片入匣 → 证据压在家书旁 → 船驶向远方 | 海风与完整但克制的航海旋律，不播国王黑化全貌 | 天赋一次性结算，再由航图主动启程；缺石时使用对应版本 |

每组 CG 支持主动跳过，跳过仍只推进到同一正确状态，不漏发或重复奖励。图像避免把可行走场景烘成不可区分的地面，CG 也不能拿来替代真实关卡的岸线、门和碰撞。

“血肉之躯，燃烧一次足矣”保留给本土最终以心脏补回光碎片的结局。本章可在炉匠旧记中铺垫：“燃烧能留下光，也能只留下灰。先想清楚，你要照亮什么。”不提前用完整名句抢走最终结尾。

## 存档与制作接入

府邸使用独立章节标识和存档空间，不能伪装为 thunder、ice 或 fire。增加第六岛时，航图、岛屿目录、敌人倍率、天赋位与旅途合并各自扩展，不能仅修改按钮名称让玩家落回旧岛。保留旧五岛字段与编号。

建议保存节点：外庭通行、开粮闸、药路畅通、身份档案已读、机关破坏、契约原令领取、骑士战胜、暗石领取、命令节点掩码、旧村出口开放、离岛告别、结局选择、各 CG 已看标志、天赋领取和三位首领专武领取。房间仍保存访问、清理、掉落与已生成奖励选项。

灯室战前恢复点单独保存，战后安全点与最终结局均不能覆盖它。暗线结局后选择恢复战前点，使用当时背包与能量状态；读档不能把结局专武带回战前复制，普通退出再进也不能再次领取胜利奖励。后续局外成长接入时单独做账户领取去重，不假定当前已有成长系统。

新章节允许精英 5 波时，在府邸自己的版本化定义与验证器中明确支持，不放宽旧五岛存档的范围校验。活跃战斗不保存半个临时动画；正常存档在安全点，Boss 重试从完整战前状态开始。

## 接入后的验收案例

- 自由提前登岛、漏读五岛线索、未学 O/P，都能理解并完成战斗；光线缺石版本不误播六石返乡。
- 普通门偏离中心能通过；渡口海面不能行走或切到其他房间；三层返回路线完整。
- 放粮、供药、读档案、停机关、骑士胜利、战后拆契约、村民放行、告别、CG、天赋和航图各自持久化。
- 光、暗及三种职业均测试；高暗储量不被清空，不因单次爆发漏阶段状态或关键物证。
- 三分之一血的 40 元素补给只有一次；专武、普通箱、结局奖励均不可通过读档刷取。
- 最终确认必须重新按键，暂时离开有效；两种暗线不当作普通失败，战前恢复点保持可用。
- CG 跳过与看完结果一致；光线先去其他岛再回来告别不重复发天赋或跳到错误章节。
