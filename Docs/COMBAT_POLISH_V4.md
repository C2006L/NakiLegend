# 战斗与工坊细节打磨

本轮在三连发／五连发基础上改善命中反馈、补给与任务对白。伤害、费用、波次数和岛屿范围沿用 [上一轮数值](COMBAT_V3_AND_FORGE_GUIDE.md)。火岛仍为黑砂海岸、锻链工坊两层 30 房，第三层与整岛 CG 尚未开放。

## 命中与追踪

- 敌弹沿上一帧到这一帧的完整路径判定，不会因为高速移动跨过玩家而漏掉命中。
- 玩家飞弹按实际接触顺序命中。箭矢先碰到前面的敌人，就不会因为后面的敌人生成得更晚而误伤后者。
- 掩体与敌人的接触顺序一起计算：掩体前的敌人能被打中，掩体后的敌人仍受保护。穿透弹遇到实体掩体仍停止，同一敌人不会被一发弹重复计伤。
- 追踪球的目标倒下或被掩体遮住时，可寻找前方六单位以内的可见目标；不会穿墙锁定、突然掉头或刷新自身寿命。普通法杖小弹与箭矢继续按发射方向飞行。

## 画面反馈

法杖小弹增加明亮小弹芯。实际接触敌人时，风显示短切痕、冰显示碎晶、雷显示折线电弧，光暗与火显示各自颜色的碎光；技能的反馈范围大于法杖普攻。

命中碎光持续约 0.16–0.18 秒，同一敌人有短暂节流，同时限制临时特效工作量。短时间内同一敌人受到的多次伤害合并为一个总数，元素克制文字也做节流，避免三连／五连发堆出一排重叠文字。每一发的实际伤害仍分别结算。

本轮复用现有独立技能与武器声音，不改已认可的音乐和刀剑音色，没有新增生成图片。

## 元素结晶与存档

原来元素还差 1 点时，拾取 8 点结晶会丢掉剩下的 7 点。现在只取走补满所需的部分，余量仍留在同一颗结晶中，之后耗能可再拾取。余量使用现有存档字段保存，换房、读档仍保留，不需要升级存档版本。

结晶吸附和拾取同时检查实体遮挡，不会从柱子、铁砧或关着的门另一侧穿过来。资源已满时仍留在地上。

## 工坊任务

阿铎的再次交谈随进度变化：救出后提醒桥西绞盘；放桥后提示摧毁巨匠身旁的铸模；击败巨匠后提示降温炉台。操作按键留在界面提示，对白改为角色在故事中会说的话。

实际路线保持：**工匠避难间救援 → 撤离桥头左侧绞盘 F 放桥 → 锻链巨匠 → 降温炉台回港**。原有金色地图目标、沿途箭头和锁门原因继续生效。

## 查看方式

停止 Play，等编译完成后重新 Play，继续原存档或按 F9 读取最近安全点。已清房间保持完成，不需要重新打岛。

测试判定与三连发可选法杖，J 攻击、L 主属性技能、U／I 元素技能；测试巨匠可用 **Tools → Naki Legend → Boss Practice → 4 Forge Master**，该练习不写正式存档。只想验证补给时，先消耗少量元素，再靠近结晶，补满后应看到余量仍留地。

验证记录见 [原生验证](../Validation/CombatPolish/README.md)。
