# 敌人意图、局部战斗镜头与首领专属招式 V1

本轮已接入前五岛的主冒险战斗。重点是改变敌人的位置关系、出手方式和应对方法，使用现有怪物形象分配不同职责；本轮没有新增怪物立绘，也没有通过统一堆血量增加难度。

## 小怪怎样配合

| 行为 | 实际规则 | 玩家可用的应对 |
| --- | --- | --- |
| 追击 | 接近后进行有起手和收招的短距离攻击 | 侧移后反击，避免被其他角色夹击 |
| 侧移射击 | 太近后退、太远接近，在中距离横向换位；被掩体挡住时寻找射击位置 | 利用掩体隔开火力，优先压迫射手 |
| 拦截 | 根据玩家近期移动选择前方及侧面目标，随后锁定一次冲撞方向 | 改变移动方向；冲撞开始后不再追踪转向 |
| 游走 | 用房间种子生成间歇变化的路线，每个目标保持约 0.8～1.45 秒；接近时冲撞 | 观察目标与蓄势，不能只跟着追击怪绕同一方向 |
| 守点 | 守住出生位置附近，不参加全图追击；近身攻击、远处散射 | 绕侧、近战或先处理外围敌人 |
| 炮击 | 在自身阵地附近活动，针对落点发动范围攻击 | 离开落点，利用间隔接近 |
| 支援 | 在同伴后方活动，短时间护阵并少量治疗附近非首领单位 | 优先切断支援；落单时仍能攻击 |

鸣沙洲示例：沙蝎追击、沙鸢拉开距离射击、风滚草游走冲撞、长枪卫守点、石像炮击。雷雨高原加入截击的巡卫与游走的铜轮；霜潮群岛有霜犬、弓手和符文炮击；赤炉群岛后段加入支援祭司；青栖林海混编虫兽、守点植物和支援单位。

主波次预算为教学 4、普通 5、后两岛普通 6、精英 7；同屏作战单位上限分别为教学 5、前两岛 7、之后 8。波次仍保留，增援受同屏上限和安全距离约束。开头两场教学保留原小编队。

路线目标有保持时间，移动转向有平滑处理，并通过现有可见性路径图绕过石柱、裂隙等阻挡；避免每帧随机目标造成抽搐。

## 预警与视野

- 普通子弹、扇形弹幕、镜面射线取消地面上的弹道预测线。普通远程攻击只保留短暂的身体／枪口亮点，实际子弹出现后躲避。
- 冲撞方向、近身挥击范围、落雷和地面范围伤害仍有对应提示。冲撞锁定方向，不能在预警结束后继续追踪玩家。
- 普通战斗镜头正交尺寸为 4.15，首领房为 4.6，随人物平滑移动并限制在房间范围；保留小地图与 M 房间地图。港口、营地等和平区域继续使用全景。
- 局部视野下，画面外的新远程发射被阻止；可移动首领会追进视野。已经发出的子弹仍按原碰撞和寿命运行。

## 五岛十五位首领的新增招式

这些招式接在原先的追击、换位与基础攻击之间，替代原来重复的统一追加扇形弹幕。约每 9.5 秒发动一次，后期阶段约 7.5 秒；场地危险有准备时间与到期清理。

| 首领 | 新招式 | 关键区别与应对 |
| --- | --- | --- |
| 鸣沙洲风蝎 | 噬雨涡心 | 固定区域持续放出旋转弹流，不要在同一区域持续绕行 |
| 巨像 | 石柱封路 | 临时升起两根有真实碰撞的石柱；不会升在角色脚下，到期撤除 |
| 猿王 | 回旋石刃 | 三枚投掷物飞出后回到首领，躲开去程后仍要留意返程 |
| 守路铜卫 | 锁链牵引 | 地面链路造成伤害和小幅牵引，切到链路侧面 |
| 引雷石卫长 | 双极雷场 | 两个固定雷场交替形成区域压力，不能只跟着首领身后跑 |
| 风暴鹿 | 逐雷追迹 | 三次错峰落雷，根据准备期落点改变节奏 |
| 裂冰甲兽 | 晶脊裂阵 | 临时晶柱与冰区改变路线，不只是放一轮冰弹 |
| 霜镜首领 | 镜面夹击 | 利用存活镜体从不同位置发射；清掉镜体削弱夹击 |
| 寒潮守望者 | 开隙潮墙 | 横向潮墙向前推进，中间保留真实安全缺口；潮水有浪尖图案 |
| 赤脊蜥 | 熔火留痕 | 连续留下三处火区，需要变换站位 |
| 锻炉领主 | 交错锻链 | 两条平行链路限制走位，注意路线之间的空间 |
| 赤潮熔龟 | 熔壳回缩 | 短时间减免正面伤害并发出弹流；正面弧形亮片方向固定，绕到侧后可正常伤害 |
| 棘甲母虫 | 孵化巡猎 | 补充不同职责的虫群并形成危险区，先控制场面 |
| 菌冠孢囊 | 孢床蔓生 | 三处孢床缓慢扩张，尽早离开重叠区域 |
| 古树守望者 | 供养根须 | 两条根路限制移动，寄生节存活时可为本体护阵；先拆寄生节 |

临时石柱同时登记脚部与子弹阻挡，房间切换、首领死亡或相关打断会清理区域及碰撞。已死亡首领的回旋投掷物也会清理。

## 如何试玩

1. 在当前 Unity 工程停止 Play，等待脚本重新编译，再进入原来的主冒险场景。菜单 `Tools → Naki Legend → Play → 1 Desert Adventure` 打开主入口；继续已有存档即可。
2. 找一个尚未清理的战斗房间，观察守点单位、射手、冲撞者的位置差异。已清理的房间不会因更新重新刷怪。
3. 查看普通子弹是否已经没有地面弹道线，冲撞线与落雷圈是否仍然清楚。
4. 用 `Tools → Naki Legend → Boss Practice` 中各岛入口直接比较首领。练习场与主冒险存档分开。

存档格式没有变化，不需要清空缓存。上轮零耗能武器、跨岛技能配置和 P 星陨三落点的修正保留。

## 验证与范围

Unity 2022.3.62f3 隔离测试工程原生运行通过 **653 项检查**，包括真实移动／绕柱、射击、冲撞方向锁定、画面外发射限制、五岛编队、十五位首领机制与清理、潮墙安全缺口、护壳侧后伤害、相机跟随及边界；并回归资源消耗、存读档、跨岛技能和完整冰岛收尾流程。

固定椭圆绕圈 32.5 秒的模拟中，混合敌群产生实际命中，守点怪留在岗位。该测试验证了这组行为不会全部跟成一列，不能代替不同装备和玩家操作下的全面难度评估。仍需试玩观察出手频率、镜头大小和远程压迫是否合适。

测试截图与结果位于 `Validation/EncounterIntentV1/runtime`。本轮覆盖前五座可玩岛屿；暮钟岛仍按既有施工范围处理。
