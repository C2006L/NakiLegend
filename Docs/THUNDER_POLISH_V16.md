# 雷雨高原 V16 小修

## 倒地体型

引雷石卫的原图在场景内使用 0.45 倍缩放，但原来的死亡代码重新创建了一个 1 倍缩放的倒地对象，因此死亡瞬间看起来放大约 2.22 倍。

倒地对象现在继承活着时的缩放、旋转与镜像方向，然后按原时间淡出。修复覆盖普通怪、精英与 Boss 的共用死亡流程；倒地姿势本身仍使用原来的帧图。

## 波次微调

只调整第二岛的十间普通战斗房，每间增加一波，普通与精英房合计由 62 波变为 72 波，约增加 16%。每波数量、伤害、Boss 和玩家成长沿用 V15。

| 层 | 加波次的房间 | 修改 |
| --- | --- | --- |
| 雨中草坡 | 旧路标坪、铜铃短桥、湿苔绕路 | 2 → 3 |
| 引雷遗址 | 铜壳校场、断槽回廊、铜架外庭 | 3 → 4 |
| 雷鸣圣所 | 风穿铜柱、裂桥边院、圣所前庭、隐雨阶 | 3 → 4 |

最初两间引导房、两个引雷节点、巡路员房以及休憩、剧情、奖励房保持原节奏。波次之间保留原来的间隔。

旧安全存档可以继续。已清理房间不会重新刷怪；还没清理的房间按新波次运行，无需重开整个岛。

## 验证

`Validation/ThunderPolishV16/ThunderPolishSmoke.cs` 在原生 Unity 中执行九类敌人及其精英状态的真实击杀、淡出和移除，检查倒地的世界尺寸与朝向。还实际清理全部 23 个普通 / 精英房，确认最后一波结束才开门、没有残留刷怪、清理状态能保存和恢复。

同时重新执行第二岛完整章节回归，检查通道、换层、节点、技能、三位 Boss 与跨岛存档；结果与原生前后截图位于 `Validation/ThunderPolishV16`。
