# 雷雨高原两房原型 S1 试玩

2026-10-27 完成首个可玩样板；设计依据为 [两房规格](THUNDER_PROTOTYPE_SPEC.md)、[D3 地图](THUNDER_MAP_D3.md) 和 [D3 战斗](THUNDER_COMBAT_D3.md)。目前开放两个房间、两种小怪、引雷机关和独立存档；第二岛的完整三层、三场 Boss、雷技能与六把新武器仍待制作。

## 直接打开

先退出 Play，等待 Unity 编译和图片导入完成。菜单选择 **Tools → Naki Legend → Open Thunder Plateau Prototype**，或打开 **Assets/Scenes/NakiThunderPrototype.unity**，再点击 Play。保持原来的 SampleScene / NakiTest 作为正常沙漠入口。

初始配置页提供三种预设：1 光路线、2 暗路线、3 基础武器；A / D 选择从 P01 或 P02 开始，F 开始，也可直接点击配置卡片与按钮。N 随时打开原型配置，R 重试当前配置。“继续原型存档”读取原型自己的安全点。

光与暗预设已开放对应 L 主技能、U 风刃、I 风波，携带免费短剑与风牙法杖，H 切换。基础武器预设没有技能且起始元素为零，仍能用 J 的免费短剑完成两房；结晶掉落照常存在。预设用于快速比较，不替代正常旅程的登岛选择与学习过程。

## 两个房间做什么

| 房间 | 战斗 | 完成后的玩法 |
| --- | --- | --- |
| P01 雨中草坡 | 三波：两只蓄雷蛾、两名巡雷枪卫、两蛾两枪卫，共八名敌人 | 北门打开，直接走过门廊进入 P02，不使用选房菜单 |
| P02 西引雷坪 | 两波，每波一蛾两枪卫，共六名敌人；未修节点在战斗中间隔预警落雷 | 靠近东北侧装置左边的铜手柄按 F，1.2 秒免费检修，Esc 可取消；完成后雷流改走右侧导能槽，可沿南门回访 |

刷怪先显示预警，初波留出准备时间，攻击前摇错开。两类怪物都标记雷属性；蛾真实拍翼，枪卫采用六帧步行与独立攻击帧，左右朝向镜像。当前采用两向表现，正式四向动画仍待扩展。每只敌人正常掉 8 元素结晶，暗预设击败有灵敌人充能。

普通雷弹可被低石挡住，也可被风波吹散。引雷节点的地面圈是锁点落雷，提前约 0.9 秒预警，风波不会消除它；短暂雷伤减免仍有效。风攻击对两种雷敌人伤害 ×1.3，第三次风命中可以打断尚在蓄力的招式。风刃击中节点附近也能短暂打断聚雷，但最终复位不要求施法或消耗元素。

两房清理后不再刷怪，换房不保留旧房伤害。地图、低石、门和引雷装置都是独立物件。修复只生成一次 20 元素结晶，满元素时留地；回访和读档不重复发放。清场后停止伤害性落雷，安全检修不会被隐藏雷区打断。

## 独立保存与继续

清房、拾取等安全进度会请求自动保存；F5 手动保存，F9 读取。战斗和未完成的检修不能覆盖上一个安全点。当前原型一个存档槽，写盘保留备份；选择新配置后，首次安全保存更新这个槽。

原型文件位于 Unity 持久化目录下 **NakiLegend/thunder-prototype-v1.json**，正常沙漠仍使用 **NakiLegend/journey-v1.json**。打开原型不读取或改写正常旅程；打开正常场景也不自动读取原型。再次启动原型先显示配置页，点击“继续原型存档”恢复，不需要打完沙漠。

保存内容包括预设、当前安全房、两房清理状态、生命护盾、三种力量、武器与备用、药剂、剩余冷却、地面结晶与装备，以及检修与一次性奖励状态。Play 中脚本重载会重建角色、小怪与地图缓存，并尝试恢复原型最近安全点；未保存的半场战斗不保留。

## 本轮适合反馈的项目

优先观察：普通雷弹与地雷是否容易区分；左右走路和持叉是否自然；门口与低石是否卡人或漏弹；免费武器是否能兜底；风杖与风刃的消耗是否合适；检修提示、取消和回访是否清楚。P01 / P02 起点可以分别反复测试。

本原型仍是场地与战斗样板，尚无完整高原地形池、灯匠 / 巡路员主线、巨鹿 Boss、雷标 / 跃电、技能装备页或跨岛航行。相关设计保留在 D2 / D3 文档，不能把配置页当作已完成的正式第二岛开场。

## 美术与验证

内置 imagegen 生成了湿石地面、低石、引雷装置、两种小怪图集、墙体、草丛与导能槽，原稿和提示保存在 [Art/ThunderPrototypeS1](../Art/ThunderPrototypeS1/README.md)。源图不作像素重绘，按实际内容边界切分：蛾 14 帧、枪卫 12 帧，每帧分别设置身体或脚底锚点。Unity 导入明确使用 Texture2D、Point、无压缩与禁 mipmap。

本轮原型通过 130 项检查，覆盖配置、真实走门、波次、实际零元素挥剑、风克雷、消弹与地雷、掩体、检修取消与一次奖励、独立文件存取及损坏备份；另通过 18 项真正脚本重载检查。画面检查使用 Unity 实际 Game View 和相机输出。验证脚本与结果见 Validation/ThunderPrototypeS1；自动检查不能替代实际操作与难度反馈。
