# 首领对局与近战接敌 V13

基准为第六座岛暮钟岛第一层的 Oath Captain（誓庭卫长），不是霜潮群岛的守卫。本轮不改变誓庭卫长的生命、招式、弹速或收招时间，也不普遍增加其他首领的生命与子弹速度。玩家武器与近战规则调整会作用于所有对局。

## 首领组合

在各首领已有的特性招式之后，加入一轮有准备时间的连续攻击。环形弹幕故意留缺口；扇形弹幕交替覆盖不同方向，攻击锁定出手时的位置而非永久追踪。新增普通弹幕不显示地面弹道线。

| 风蝎 | 涡心后接带缺口的错位环弹 |
| 巨型石像 | 石柱改变路径，石像凝视缓慢扫射并接扇弹 |

## 自然收招

约 3.5 秒收招规则保留。到时间后先停止开启下一招，已经承诺的连发和激光完成后再进入慢速换位。已飞出的子弹不会在收招时消失。小怪不使用首领收招窗口。

## 近战与法杖

- 剑与长矛实际武器输出提高 15%，法杖实际武器输出降低 12%；弓弩和技能伤害不因本轮调整而改变。背包伤害说明使用同一输出计算。
- 所有专长使用近战武器时，一次挥击最多削除正面近距离的三颗可消除普通子弹。长矛仅沿窄刺击方向生效；背面子弹、激光与地面危险区仍然有效。
- 反弹子弹天赋继续保留反射效果，基础削弹不获得反射能力。
- 战士实际近战出手期间受伤降低 30%，被打中不会取消尚未落下的这一击；站着持刀、空闲及持远程武器时不触发。减伤不等于无敌，也不额外回复护盾。

## 验证和试玩

隔离 Unity 项目通过 1286 项检查，覆盖所有 17 个增强配置、准备阶段、真实弹幕生成、激光伤害与遮挡、收招自然衔接、誓庭卫长未加入攻击包、有限削弹与战士减伤。并复测暮钟岛房间、任务和旧档流程。自动验证能检查规则，最终难度仍需实战比较初始武器与强力武器。

旧存档可继续，停止 Play、等待脚本导入后重新运行即可。使用原有 `Tools > Naki Legend > Boss Practice` 各首领试炼，可分别用战士与法师对比；练习不覆盖旅程存档。无需清空缓存或重打前面岛屿。
