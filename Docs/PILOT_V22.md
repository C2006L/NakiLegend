# 首领样板调整 V22

本轮采用古渠巨像、棘甲母虫、封港统领作为机制样板，不再统一提高首领血量。

- 修正王都弩车死亡时读取通用王印柱贴图的问题。死亡姿态按机关所属首领选择原本造型。
- 三位王都首领各接入 12 个独立动作帧：四帧行走，以及起手、攻击、受击、败退、防守、施法、整备、待机。统一 PPU 和脚底锚点；取消同一站立图充当全部动作帧的做法。
- 快弹使用宽头红色锥形轮廓与浅色中心，替换缩得很细、透明留白较多的箭图。慢弹使用高对比圆环与半透明内芯。视觉尺寸不改变原有弹丸碰撞半径。
- 古渠巨像和封港统领可发出明显更大的母弹：短暂转向后锁定方向，撞墙或寿命结束分裂为四颗普通弹，子弹不再分裂。命中玩家不会再追加分裂爆发。
- 预判在发射或动作起手时完成；普通快慢弹不持续跟踪。巨像的接近步伐使用玩家运动预判位置。
- 一般召唤物使用同类普通怪约七成生命，同时限制存活与待出场总数为四只。母虫继续使用较弱召唤物，总数上限三只。
- 母虫生命单独降低约 10%；第一层为 2520。孵化特性间隔延长到十秒，取消叠加的通用齐射，减小专属大扇面弹幕数量。
- 光之力按修习等级成长为 90、105、120、135、150、170。辉光束单次伤害脉冲从 5 调为 4.5；守心光幕持续时间、武器输出与元素技能配置保留。旧存档仍可读取，超出新上限的当前光能会校正。

本轮保留移动收招、命中压制、激光掩体阻挡和现有首领血量表（母虫例外）。不以回归测试通过数量代替真人手感判断。
