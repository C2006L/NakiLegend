# 森林摆放与战斗数值 V4

## 地图与掉落

截图中墙外的树桩来自 `BuildWoodlandEdges`：旧位置是 `±(房间半宽 + 0.65)`，而不是怪物掉落装备。改为战斗房间墙内两处小型树根掩体；自然掩体按整张 Sprite 的尺寸与脚底轴心留出 0.35 单位墙内边距，避开门口、楼梯和剧情机关预留区。树根同时具有行走及弹道碰撞，不再出现能穿过的墙外装饰树阵。普通房间已有的倒木、树桩布局继续保留。

武器、能量结晶在生成及重新绘制时统一检查落点：必须位于房间地板内、远离门道并可拾取。旧存档里位置不合适的地面物品就近迁移，物品 ID、能量数量保持不变。不改变房间编号、存档格式、背包内容或玩家选择的技能。

## 武器

以下是基础数值变化，元素克制、装备专有效果和角色成长继续单独计算。

| 类别 | 调整 |
| --- | --- |
| 刀剑、匕首、镰 | 直接近战伤害 +15% |
| 长矛、长枪 | 直接近战伤害 +12% |
| 锤、槌 | 直接近战伤害 +22% |
| 弓 | 满蓄从速射伤害的 6 倍改为 5 倍；速射不变 |
| 弩 | 满蓄从速射伤害的 6.5 倍改为 5.5 倍；速射不变 |
| 元素三弹法杖 | 每弹伤害降低 10%，仍然一轮付费一次 |
| 元素散射法杖 | 五弹每弹系数 0.55 → 0.50，降低贴脸全中的收益 |
| 凝聚法杖 | 单弹系数 2.4 → 2.1，保留穿透用途 |
| 引雷针类 | 单弹系数 1.6 → 1.5 |

法杖公共系数 0.8、光之杖与贤者魂灯的专用弹数/系数保持。满蓄额外能量、K 保留蓄力、穿透等专有效果继续生效。零耗能弓弩满蓄依然免费，背包说明也正确显示免费。伤害卡片、拾取提示与实际发射共用计算函数。

## 技能

战士、弓箭手无天赋时，风刃/冰锥/火种/回旋风刃仍消耗 4 元素；缠根从 5 降为 4，雷标/孢子从 6 降为 5，护身风波/跃电/护甲脉冲从 7 降为 6，霜环/烬环从 8 降为 6。法师 15% 元素减耗及相关天赋叠加规则不变，界面显示实际消耗。

- 雷标基础伤害 22 → 30，保留固定落点、延迟命中与最多三个目标。
- 霜环基础伤害 14 → 22，冷却 5 → 4.5 秒，普通怪减速 3 秒、首领 1 秒；更适合被围时脱身。
- 跃电冷却 3 → 2.6 秒，保留跳电用途。
- 贤者之石无上限储能、流星每次 1 点、蚀魂印/星陨联动和光之力激光路线保持。

此次不提高怪物血量、攻击力或波数，避免将玩家截图中的低血低护盾状态进一步推向单纯数值压迫。重点调整武器机会成本和控制技能使用空间。自动化验证能检查数值实际生效，最终手感仍需真人连续战斗测试。

## 试玩

退出 Unity 播放模式，等待重编译，再运行原来的主冒险场景。使用继续旅程或 F9 返回原存档，无需重新清岛。优先测试棘甲母虫房的左右墙、门口通行、掩体挡弹；对比刀剑近身、弓弩满蓄、喷杖贴脸以及霜环控场。技能槽保持自己的配置。

验证脚本和结果位于 `Validation/ForestBalanceV4`，使用隔离 Unity 项目及独立测试存档，不读取或覆盖真实玩家存档。逐武器实测输出为 `runtime/weapon-balance.csv`。

本轮 Unity 2022.3 原生回归通过 3,846 项检查，包含森林 45 个房间的三组种子布局、门口落脚、怪物候选落点、异常地面装备/结晶重定位、133 把武器的实测伤害与资源扣除、霜环/雷标、旧流程和府邸回归。另行复核了森林首领房与普通房实际渲染。编译无错误，保留已有的验证专用 `chapterBatchSaveDirectory` 未静态赋值警告。
