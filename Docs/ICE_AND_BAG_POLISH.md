# 背包与冰岛四项修正

满背包拾取武器时，六个格子现在都可用 A／D 或鼠标点击选中，按 F 或“替换所选”确认。可替换携带 1、携带 2，以及四个备用格；被换下的物品放回地上，其他五格不变，当前使用的武器栏不自动切换。取消会保留地上的新物品。界面不再使用遮住格子的居中弹窗；替换期间也不会误触丢弃或使用补给。

冰岛受困营地救援后，移除地面的五根占位横条。营门入口正常开放，绞盘、围栏和获救队员保留；救援未完成时的门口碰撞仍在。

冰弓手的两支箭不再继承普通圆弹的描边和亮芯子物体。箭身、冰色和短尾迹保留，发数、弹速和伤害不变；删除子物体前先隐藏，避免一帧残影。

提醒返回营地的路牌改为带深色边框、木纹、铁钉和雪帽的样式，箭头两笔真正汇合，避免画成交叉符号。按房间连接寻找通向受困营地的路径，把牌放到相应出口旁；靠近提示“破冰队营地 · 沿此出口返回”，救援完成后不再显示过期指路牌。其他现有路牌也使用修正后的箭头构造。

没有改动存档结构。停止 Play、等待编译后重新运行，F／F9 继续原存档；已经完成救援的档直接显示开放地面。满背包时在地上武器旁按 F 即可尝试新的替换界面。

原生验证和实际画面见 `Validation/IceBagPolish`；本轮未替换声音或生成新图片，路牌沿用现有代码绘制系统。
