# 雷雨高原首个原型：草坡战斗房与引雷机关房

状态：D2 验收规格，尚未实现。章节内容与全部房间身份见 [第二岛详细设计](THUNDER_PLATEAU_DESIGN.md)。本批 V14 已推送的改动只涉及第一岛与通用系统；不要将本文看作 Unity 中已经存在的新场景。

## 第一次做多大

第一步只建两个能用门实际往返的房间：P01 湿石草庭、P02 西引雷坪。门、地面、掩体、敌人均为独立物件与数据；不把整张概念图放在地面上后据图猜碰撞。既有少年动画、手掌握点、自动瞄准、护盾、元素结晶和敌人房内移动继续复用。

P01 有蓄雷蛾和巡雷枪卫两类敌人。P02 战后让玩家拨动手柄，恢复一段引雷设施，观察雷从路上转向导能槽。两房闭环要先证明：风有优势、没有风也能完成、零元素不困住玩家、门口不会夹人、回访与存档不重复奖励。

这一步不做完整三层、巨鹿 Boss、技能装备 UI、雷标 / 跃电、跨岛航行、支线 CG 或随机天气伤害。独立调试场景不能读取或覆盖正常沙漠存档。

## 尺度与分层

| 项目 | 原型初值 | 检查目的 |
| --- | --- | --- |
| P01 可走边界 | 18 × 10 世界单位 | 给闪避与侧绕空间，不靠缩小角色掩盖堵路 |
| P02 可走边界 | 18 × 11 世界单位 | 导能槽位于边缘，不横截唯一出口 |
| 少年画面尺度 | 复用 V14 像素身体、相同 PPU 与镜头尺度 | 与沙漠一致，杜绝重新放大立绘 |
| 门净宽 | 至少 1.8 单位，四向统一 | 满足身体与转向，不按门图片透明边算净宽 |
| 门内安全带 | 宽至少 2.4、深至少 2 单位 | 不放柱子、刷怪、教学台或机关 |
| 低石掩体 | 两块，宽约 1.2、高约 0.65 | 身体判定与挡弹体可单独校准，但视觉边缘吻合 |
| 房间移动 | 敌人与玩家换房逻辑分离 | 敌人不能走进通道；关门前做房内恢复 |

地面灰苔石、湿土与草边三类小块拼接；墙体 / 崖边、门框、掩体、灯、导能槽分层。角色按脚底 Y 排序，雨与背景云不遮挡预警，HUD 不盖住南门交互提示。可走浅水要有连续地面边缘；深沟是明确边界。

计划制作的美术不直接取概念图切出模糊局部。地面模块以 32 × 32 像素基准规划，较大道具可用整数倍，最终 PPU 先对齐少年素材。导入 Point、禁 mipmap、合适透明边距，防止图集邻帧渗色。图集逐帧单独检查边缘与握点。

## P01：湿石草庭

玩家从南侧缓冲区进房，北门连 P02，左右低石错开但中间保留超过 2 单位的通路。首次入房给 1.5 秒安全准备，刷怪提示亮起后才封门；封门不瞬移或伤害玩家。

| 阶段 | 出场 | 教学与约束 |
| --- | --- | --- |
| 第 1 波 | 两只蓄雷蛾 | 首只在远处单独亮腹；第二只延后 0.8 秒。弹幕有间隙，普通移动和石头都能应对 |
| 第 2 波 | 两名巡雷枪卫 | 每次至多一个主动直刺；不出生在门内、低石、玩家脚下 |
| 第 3 波 | 两只蛾＋两名枪卫 | 同时高威胁前摇上限二，并错开；验证风刃与风波价值 |

清完一波等 1 秒，下一波刷点再提前 0.8 秒提示。清房清除残余有害弹、开启北门，字幕只短暂提示，不打开选关菜单。两种敌人掉落按 V14 普通 8 元素结晶；暗线有灵敌人按 +12 暗之力。满元素结晶留地，离开再回保持原地。

技能说明只出现一次，可在暂停页重看：风刃对雷伤害提高；风波能消普通飞弹；石头可挡弹。没有风技能时只显示基础走位提示，不弹出必须学习的门锁任务。

## P02：西引雷坪

中间宽走道，东侧铜节点与沿边导能槽，西侧检修手柄。初次进入时设备对场内一个小区周期聚雷，只先演示一次，给玩家完整预警；战斗阶段配置一只蛾、两名枪卫的两波组合。初版不同时摆两个雷区。

| 状态 | 可做的事 | 保存内容 |
| --- | --- | --- |
| 未清理 | 移动与战斗；手柄提示先确保安全 | 不覆盖安全点，不保存半场敌人 |
| 已清理、未检修 | F 调查，提示失衡来自错误连接；F 扳动手柄 1.2 秒，Esc 可取消 | 只记清房；取消不记完成 |
| 检修完成 | 雷流改道至边缘，暖灯亮起，门保持开 | repairComplete，一次性奖励生成状态 |
| 回访 | 可检查设施；无再刷战斗或再领奖 | 保留落地奖励、领取和回访状态 |

机关主路操作免费。风击中蓄力节点可打断当前预警，帮助安全观察，但机关最终复位也能靠手柄完成；不做必须施法才能解锁的门。暂定一次奖励 20 元素结晶，满时留地；完成标志和奖励生成必须在同一进度提交里，避免读档刷结晶。

两房原型先使用独立验证数据，不在正常 V1 存档中硬塞第二岛房间。正式跨岛接入按详细设计做 V2 迁移后，再让相同状态使用正式保存系统。

## 雷击与风的边界

普通雷弹：有轮廓的蓝白小弹，具实体碰撞与可消弹标志。风波清掉的是实弹物件，不能只隐藏特效。导能槽落雷：地面空心圈、边缘倒计时和独立音，0.9 秒后结算，锁点后不追踪；风波不能清除地面雷区。环境远景闪电没有 Collider、伤害或攻击状态。

风伤雷维持 ×1.3。三次风命中触发一次破势，破势间隔 6 秒；只取消仍处于前摇的攻击，不撤销已经发生的落雷。风波雷伤减免维持 30% / 1 秒。UI 用文字与形状说明区别，不因有护身风波就误导玩家站着接落雷。

## 首批素材的动作规格

| 内容 | 初版动作与帧数目标 | 必须肉眼通过 |
| --- | --- | --- |
| 蓄雷蛾 | 待机 / 飞行 6 帧、亮腹蓄力 4、出弹 3、受击 2、退场 4 | 翅膀确实开合，身体基点稳定；不是仅上下漂浮 |
| 巡雷枪卫 | 四向待机 4、四向走路 6、直刺 6、抬叉发弹 5、受击 2、退场 5 | 左右都交替迈腿；握点跟随手，不把武器留在原地 |
| 引雷节点 | 静止、预警充能、改道后稳定三状态 | 暗态与完成态形状不同，不只有改颜色 |
| 灯和导能槽 | 小幅亮度变化与少量电弧 | 不全屏闪白，不压过攻击预警 |

帧数是制作预算，不等于已产出的可用图集。先做单方向短循环预览，再扩四向与攻击；可以镜像的方向也必须逐帧检查腿、手和挂件。敌人脚底 / 翼根锚点与受击体分开定义。正式运行不把概念图中的阴影当作身体判定。

## 入口与测试方式

计划新增独立场景 `NakiThunderPrototype` 与 Tools 菜单入口，明确标注“第二岛两房原型”。配置光、暗、无风技能三种可选测试预设，并提供 P01 / P02 起点，不要求先打完整沙漠。每次启动选择是否恢复独立原型进度，默认不触碰主旅程档。

验证完成后才接跨岛：沙漠归渠水道 CG 完成 → 安全营地航行提示 → F 确认 → 读取 / 创建高原入口 → 保存 V2。未开放第二岛时保持“航线待开放”，不设置空目标门或落入不存在场景。

## 交付验收

| 检查 | 通过标准 |
| --- | --- |
| 门和出生点 | P01/P02 四向门模板、三种进入方向与两种人物状态均无卡死；封门时敌人整体在房内 |
| 掩体 | 来自上、下、左、右与斜向的普通弹命中低石边缘都被阻挡，不越过图像底座 |
| 波次 | 每波敌人总数、场上上限、刷点预警与高威胁并发符合表格；清房只结算一次 |
| 风克雷 | 相同装备命中下能测出 1.3 倍；三次破势与 6 秒间隔可复现 |
| 风波 | 清普通雷弹；不消地雷；雷伤减免到时结束，切房不留永久减伤 |
| 无资源流程 | 零元素与零暗之力，持免费物理武器完成两房与手柄操作，没有软锁 |
| 动画与持物 | 录制四向走路和攻击，左右迈腿正常，叉柄在手上，图集无邻帧碎片 |
| 回访 / 存取 | 清房、检修、落地奖励在回访和独立测试恢复后保持；失败写盘不破坏前一安全状态 |
| 表现 | 预警不被雨、草、门或 HUD 遮挡；游戏画面没有调试矩形替代交互道具 |
| 第一岛回归 | 原 39＋5 房、光暗、F5/F9、三种 Boss 与 CG 的已有检查继续通过 |

原型先记录普通玩家光 / 暗各一轮，并做无风、零元素的边界检查。是否扩整层以通行、读招、动作与资源收支为依据；不以概念图精美程度代替可玩验收。
