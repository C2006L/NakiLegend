# 血量与首领输出窗口

按最新反馈，相对于 V7 统一将小怪血量降至 75%、首领降至 65%。适用于前五岛和暮钟岛当前实装的首领，包括鸣沙洲守关者的独立血量设置；各岛原有强弱顺序保持。暮钟岛誓庭卫长实际血量从 6,120 降至 3,978。武器、技能伤害和能量消耗保持。

首领战敌方子弹移动速度降至原来的 75%，同场援军子弹也采用这一倍率。普通清房战子弹速度保持。

各首领拥有统一节奏：约 7.5 秒进攻段后，进入 3.5 秒收招输出窗口，头顶提示“收招 · 反击时机”。进入窗口时停止冲锋、取消蓄力、残留敌方弹和延迟弹幕，关闭举盾与当前首领攻击区域；援军暂停进攻，玩家仍可移动和使用武器技能。窗口期间忽略尚未消退的环境伤害，保证可实际输出。结束后恢复原有招式循环，阶段召唤记录保留，不因收招重复召唤。

房间切换清除窗口状态；战斗死亡或离开房间不会把输出窗口带到其他房间。现有装备、路线和章节存档保留，新血量在重新生成敌人时生效。

隔离 Unity 测试通过 50 项检查：逐岛检查小怪／首领倍率、收招进入与 3.5 秒时长、残留伤害保护、停止敌方发射、弹速倍率、窗口结束，以及实际卫长血量。验证使用已有本地依赖启动，不改动正式存档。

试玩：先停止 Play，等待 Unity 编译，再 F9 继续安全点并重新进入战斗。已清理房间不会重新刷怪；也可使用 Boss Practice 独立练习模式。
