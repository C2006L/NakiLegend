# 武器外观、音色与主属性武器

本轮解决了同一张法杖图被多把装备复用、三个变体共用外观、发射和命中音只按类别选择的问题。旧的 0～122 号武器保留编号，新增武器放在 123～131；旧背包和掉落按原编号继续读取。

## 查看与试玩

在 Unity 等待导入与编译结束，打开 `Tools → Naki Legend → Design → Weapon Gallery`。图鉴可以搜索名字或编号、查看全部 132 把外观、试听每把的发射与命中声音；图鉴不会修改存档。游戏里按 B 比较武器，H 切换，J 攻击；弓弩按住 J 蓄力、松开发射，K 保留蓄力。

已有装备重新运行后直接换上新图与特效，不需要重开旅程。新装备进入对应路线的补给候选池，并按照来源岛屿逐步出现；已领取的箱子不重抽。仍可使用另一栏的普通武器，避免主属性能量不足后失去反击手段。

## 外观与战斗表达

- 全部 132 个条目各有独立图像区域，手持、地面、背包、奖励卡和图鉴读取同一份绑定。图像共用图集，但不共用武器区域。重槌保留真实锤头；弓弩朝向、手柄和最长边比例单独处理。
- 引雷针杖使用细雷针与短电痕，角灯灵杖使用悬灯、环形雷印和封印状命中效果。两者不再同时显示橙色法杖。
- 弓弩保留细箭/弩矢、短尾迹；长枪显示前刺细痕，剑显示弧形刃迹，重槌显示放射碎击。每个编号有独立的纹章、尾迹参数、色阶和命中纹样。技能继续使用自己的表现。
- 27 个三变体家族分别区分轮廓。原“散华 / 凝聚”按类型改为“簇射 / 贯流”“翼矢 / 重弦”“回锋 / 裂刃”“分岚 / 穿阵”，已有变体机制与编号保留。
- 264 个武器声音文件分别用于 132 件装备的攻击与命中，以既有许可 Foley 为基础重新组合短促材质、接触延迟和衰减；没有复制其他游戏音频。音乐和技能音频文件保留。
- 延迟连射、碎裂弹、侧箭记录发射时的武器编号，发射后换武器不会改变后续弹的外观。木杖中毒与声音字段分离，保留中毒效果。

## 法杖削弱

所有法杖的实际单弹伤害统一乘 0.8，完整命中一轮的伤害较上一版降低 20%。没有通过提高耗能来间接削弱。三弹、五弹、单发雷针和贯穿变体继续保留差异；背包改为显示“每弹伤害 × 数量”，避免把单弹基础数值误认为整轮数值。其他武器及主属性技能的基础伤害未随本次法杖调整改变。

弓弩蓄力超过起始阈值时额外消耗 1 点对应资源，界面按实际资源显示。法师对元素之力的费用折扣不会套用到光之力或贤者之石能量。

光系武器需要光之力路线，魂器需要贤者之石路线。普通元素武器继续消耗元素之力，不会因为攻击带紫色效果而偷偷换资源。资源不足不会借用其他能量槽。两种主属性的资源仍分开保存，贤者之石能量继续无上限，魂器不会因储能无限而无限放大武器伤害。

游戏中的资源提示、技能卡、路线选择、背包、天赋和手记统一使用“贤者之石 / 贤者之石能量”；内部枚举与旧存档字段保持兼容。暗黑大骑士和玩家指定的“暗黑低语匕首”等专名保留。

## 资源与验证记录

生成图集、原始来源路径、裁切区域与逐文件摘要记录在 `Tools/WeaponIdentityV3`、`Art/WeaponIdentityV3` 和 `Resources/NakiArt/WeaponIdentityV3/manifest.json`。图集原图保留，Unity 原生切片；准备脚本仅分析像素透明边界，不重绘或改写图像。音频来源与峰值/RMS 记录在 `Art/WeaponIdentityV3/audio-audit.json`。

独立 Unity 回归位于 `Validation/WeaponIdentityV3`，覆盖旧五岛、首领移动、航行和存档，以及逐件武器的外观、发射、源编号、声音、法杖削弱和主属性扣费。实际手感仍需要玩家试玩反馈。
