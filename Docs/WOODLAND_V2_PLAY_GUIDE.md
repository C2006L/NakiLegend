# 第五岛·青栖林海 V2 试玩说明

本轮在原有三层 45 房基础上完善森林地图、独立战斗机制和结尾，没有增加房间总数。正式顺序是沙漠 → 雷雨 → 冰岛 → 火岛 → 森林，之后的大骑士府邸尚未接入本轮。

## 怎样打开

1. 停止 Unity Play，等待脚本编译。
2. 菜单 **Tools → Naki Legend → Play → 5 Woodland Adventure**，再点播放。
3. 有森林安全存档时继续原进度；没有时可选择起始层、光暗预设和职业。正常主线也可从火岛结尾后的码头确认前往森林。
4. F 互动，B 行囊，T 将元素技能装到 U/I；L 保留光／暗技能。F5 在安全房保存，F9 读取当前岛的安全点。

只测试 Boss：**Tools → Naki Legend → Boss Practice** 下的 **5 Thorn Mother**、**5 Spore Crown**、**5 Ancient Guardian**。练习不会覆盖正式章节进度；旧的 **5 Woodland** 入口也保留。

## 地图与节奏

| 层 | 地形与重点 | 守关者 |
| --- | --- | --- |
| 雾岸林缘 | 新林地地表、低树桩、苔藓倒木，学习绕掩体与应对冲锋 | 棘甲母虫，独立大甲虫形象、蓄力冲撞与种刺扇射 |
| 朽木腹地 | 独立菌地地表、营救采种人、调查不同自然痕迹 | 菌冠孢囊，延迟孢雾、分段弹幕 |
| 树冠旧庭 | 独立古树地表、组合敌群、解除古树寄生束缚 | 古树守望者，寄生结节、二阶段追加弹幕 |

普通战斗房通常 4 波，精英房 5 波；第一层最初两间战斗房为 3 波。基础波次约 5～7 只，再加已有近战增援；同波限制远程单位与冲锋鹿数量，增援出现前有预警。实际难度仍需玩家试玩调整。

树桩与倒木接入行走、弹体阻挡；不同房间采用不同摆位，并给出入口、任务物件与到达点留空。原有 45 个房间的编号、连线和清房状态保持兼容。码头使用有岸线、栈桥和水域碰撞的完整港口画面。

## 敌人和元素

- 十类普通生物按层逐步加入：针尾蜂、棘甲虫、裂荚株、匍藤猎手、灰孢团、苔背盾卫、腐叶蜈、吞苔蛙、引荧螟、寄枝鹿。森林战斗已从旧高原 AI 分离；盾卫近战追击、蜈蚣不再误带石像精英属性。
- 引荧螟会给附近同伴短暂叶障；棘甲虫／盾卫的正面防护可通过绕侧应对。火焰可绕过这些叶障和甲壳减伤，并保留火克木的伤害增益。
- 敌方孢雾先预警至少 1 秒，再造成伤害；小范围、有限持续时间，同场最多 3 处，不生成在门口。火弹和焰环能真正烧掉孢雾。
- 玩家孢种命中后附加 3 秒持续伤害，重复命中刷新时间，不无限叠加。
- 古树有 3 个可攻击的寄生结节：打破会削弱古树、打断已排队弹幕并打开反击窗口；结节不产灵魂和能量，不能刷资源。古树仍可以直接击败。第二阶段保留预警和停顿，再增加延迟追射。
- 所有 Boss 沿用首次存活血量降至三分之一时掉落总计 40 元素能量的补给规则。光／暗能量与元素之力继续分开计算。

进入森林基础护盾上限至少为 8；击败第二层守关者后再增加 1，按进度推导，反复读档不叠加。正常航程保留装备、职业、天赋以及已学的火与冰技能，T 可重新搭配。

## 剧情与结尾顺序

1. 在第一层守关后翻阅林册，领悟根刺。
2. 在第二层清除笼外守卫，用钥匙救出采种人；调查三处自然痕迹中的任意两处，才能进入菌冠房间。调查奖励只能领一次，重复互动不会刷能量。
3. 第二层守关后拾取孢种，进入古树旧庭。
4. 击败古树，取回木石，带着林册与种子返回林缘种床，完成栽种；栽种不消耗元素，空蓝也不会卡主线。
5. 回码头与阿苓交还林册，播放新绘制的结尾 CG **“旧叶落处，新芽有声”**。
6. CG 结束才进入一次三选一天赋。选完留在森林，不会自动跳回雷雨高原。

码头返航有单独确认，只会读取火岛自己的安全点；找不到火岛存档时留在森林并提示。森林进度独立保存。

## 新武器与存档兼容

六把森林武器追加在现有目录末尾：竹节轻弩、木髓枝杖、盘根长枪、朽芽重锤、青脉藤弓、采枝短刀。按职业在奖励房掉落，并在精英战斗增加对应奖励；没有改写玩家已有雷／冰武器的名称、属性和编号。近战武器继续复用既有正确类型的素材；远程装备已更新为藤木、竹节主题图像，补给箱还有新增法杖、弓和弩以及恢复选项，见 [补给箱更新](ISLAND_SUPPLIES_AND_PACKBEAST.md)。

旧森林 `w3-v1` 存档升级到 `w3-v2`，保留清房、任务、天赋和地上掉落，并把旧森林重用的武器编号映射到新目录。已通关但缺少结尾 CG 的旧档会补播，已领取天赋不会重复奖励；写回时保留原文件备份。本轮没有删除玩家存档或改写既有场景文件。

## 美术与验证范围

新增图像在 `Assets/NakiPrototype/Resources/NakiArt/WoodlandV2/`：三种地表、自然物件／母虫透明图集、结尾 CG。生成提示词与来源记录在 [prompts.json](../Art/WoodlandV2/prompts.json)。普通敌人的专属逐帧动画仍未制作，本轮重点是地图、行为、任务链和结尾连接。

Unity 原生回归与实际渲染验证记录见 [Validation/WoodlandV2](../Validation/WoodlandV2/README.md)。自动检查覆盖状态、碰撞、资源、存档与结尾顺序；不等同于人工完成整岛的战斗手感测试。
