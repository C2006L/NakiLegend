# 六岛顺序、克制链与贤者之石：整体修改规划

状态：已确认的制作方向；本文列出的数值和章节迁移尚未实装。本轮实际修改只有流星释放音效。

## 1. 正式主线

沙漠岛〔风〕→ 雷雨高原〔雷〕→ 冰山岛〔冰〕→ 烈焰岛〔火〕→ 森林岛〔木〕→ 大骑士的府邸〔暗〕→ 本土王城。

光／暗职业路线仍在沙漠登岛时确定；战士、法师、弓箭手的专长独立于路线与元素。五种自然元素碎片加暗碎片共六片，回本土后的国王冲突、光元素来自少年心脏的真相继续保留。初期右眼的贤者之石是人工淬炼的容器，府邸守护的才是 Naki 魔法石真正的暗元素核心，避免开局已持有第六片的矛盾。

已完成的森林岛地图、生物、美术、武器和剧情保留，调整为第五岛；第三岛开始制作冰山，第四岛为烈焰。不要把当前木岛简单换成红色后冒充烈焰岛。

## 2. 元素规则

本作采用魔法克制环：风克雷、雷克冰、冰克火、火克木、木克风。强克制默认 1.3 倍伤害；其他组合默认 1.0，首版不再叠加普遍的反向减伤，以免惩罚自由搭配。

克制按目标的弱点和材质计算，不按整座岛统一计算。物理、光、暗不加入自然元素闭环，继续承担保底输出和路线技能职责。倍率只能计算一次，不能同时按元素、木材质和燃烧状态乘三次。

| 岛 | 前岛能力的机制收益 | 当前岛获得的能力方向 |
| --- | --- | --- |
| 沙漠 | 以武器、光暗技能入门 | 风刃、护身风波；保持修渠后才有甘泽 CG |
| 雷雨高原 | 风打断聚雷，风波削弱雷伤 | 雷标、跃电 |
| 冰山 | 雷击破特殊冰晶装甲、激活导能晶柱；这是魔法规则，不用现实导电性硬解释 | 冰锥、霜环：单体冷却与小范围减速 |
| 烈焰 | 冰冷却熔火护甲、暂时压制危险地面 | 火球／烈焰斩、焰环：直击与有限燃烧 |
| 森林 | 火烧开荆棘、击破寄生外壳；保留幼芽保护目标 | 根刺、孢种，逐步完善持续伤害和控制 |
| 府邸 | 五种元素破解不同房间机关与敌方招式 | 暗元素核心与路线终局 |

同岛保留中性敌人，例如普通甲虫、青蛙并不因为住在森林就统一弱火。Boss 弱点提供明确窗口，不能跳过全部阶段；没有携带克制技能也必须能用基础武器完成。

技能槽保持 L 主属性、U/I 两个自然元素，H 两把武器切换；通过安全营地与行囊配置，避免添加更多常驻按键和卡片。

## 3. 贤者之石数值首轮调整

| 项目 | 当前代码 | 下一轮目标 |
| --- | --- | --- |
| 上限 | 100 | 100 |
| 暗路线初始能量 | 24 | 6 |
| 普通有灵敌人击杀 | 12 | 2 |
| 精英有灵敌人击杀 | 通常同普通 | 3 |
| 有灵 Boss 击杀 | 通常 24；部分 Boss 排除 | 3；是否获得由剧情与生物资格决定 |
| 一次流星 | 8 能量，两颗球 | 1 能量，两颗球共同消耗一份 |
| 每颗球基础伤害 | 10 | 15 |
| 储量伤害加成 | 最高 35% | 最高 20% |
| 冷却 | 1 秒，并且有任意旧光暗球时阻止施放 | 1 秒；改成最多同时两组、四颗球 |

目标公式：每球伤害 = 15 × 岛屿技能成长 ×（1 + 施放前储量 / 100 × 0.2）。计入弱点或目标防御时仍走统一伤害系统，不直接绕过护甲。

每次施放只扣一次能量；只有至少生成一颗有效法球才完成扣费与冷却。全被贴墙阻挡时不浪费能量。一颗先命中后，另一颗仍正确保留；同时存在的组数用施法组 ID 计算，不用单颗球数量粗略猜测。

示例：初始 6，击败普通生物后 8，释放一组流星后 7；再击败精英后 10。两个弹体不各扣一次，穿透、毒伤最后一跳、反击等击杀路径也不能重复充能。

灵魂资格改成敌人定义中的明确字段：普通敌对有灵生物可充能；石像、机械、扎根机关、召唤物、已经结算过的尸体不充能；巨鹿和古树等剧情幸存者不充能。休息、元素药剂与普通元素结晶仍不补暗能。击杀、能量不足、技能卡片与存档恢复提示统一更新。

暗系应当有鲜明的进攻优势，不额外加上不断掉血或强制能量衰减来抵消本轮加强。保留光系自然恢复的持续性，并用实际清房速度与 Boss 战测试确认强度。

## 4. 新岛剧情与战斗设计方向

### 冰山岛：冻结的回声

冻结的潮汐使港湾无法换气，灯塔记录停在同一个冬夜。少年帮助守塔人找到失踪的破冰队，进入封住潮门的冰晶设施。三个区域按冰港外缘、冰封回廊、极夜晶庭推进；计划敌人覆盖冰甲冲锋、碎晶远射、薄冰诱导与短时寒雾，不以全程滑地剥夺控制感。

Boss 候选为裂冰甲兽、晶柱守卫、霜冠守护者，正式美术前逐个定稿。雷技能可击碎部分晶甲、关闭导能护盾；先演示安全弱点再组合进 Boss。取回冰石后，玩家亲自解开潮门、送破冰队返港，再播放海湾重新呼吸的尾声。

### 烈焰岛：让火找到归处

地火从被抽空的岩脉中涌入居民的旧居。少年跟随铸炉师穿过灰烬海岸、熔炉腹地、赤焰火山庭，重新为熔流留出出口。冰技能暂时冷却敌方熔壳和局部危险区，不能让玩家无限冻结整张地图。

Boss 候选为熔甲兽、炉心铸像、赤焰守护者。攻击围绕蓄热、喷发和冷却窗口设计，预警先于判伤。取回火石后完成引导熔流和居民撤离的实际交互，再到下个岛。火不是纯粹毁灭，也可以为新生清出空间。

### 森林岛：旧叶落处，新芽有声

沿用已制作的 45 房、十类生物、三位 Boss 和采种人故事；根据第五岛的队伍成长重新调节组合、行为和血量。新加可焚荆棘、寄生组织弱火与有限燃烧；古树和幼芽仍需保护。保留 Boss 后返回种床、免费栽种、交还林册的尾声，不能变成烧完整座森林。

### 大骑士的府邸

顺序为废弃外庭、府邸回廊、最后的村落与骑士厅。以元素组合和资源准备检验前五岛的能力，不把暗元素当作普通元素环的最后一个弱点。

保留暗路线“一人份的贤者之石”的悲剧与反噬真相，光路线回收暗元素核心后返回本土。终局中的“完整人类灵魂”和普通战斗能量点要区分：不能在开战瞬间无提示地把玩家攒满的能量强行清成 1。制作府邸时先完成资源规则与剧情选择的联合原型，验证加强后的流星不会让原有终局失去逻辑，再制作 CG。

## 5. 章节、成长、存档与工具入口迁移

1. 增加明确岛屿 ID：desert、thunder、ice、fire、woodland、manor；显示顺序与存档文件名分离。现有 woodland 文件名继续识别，不因从第三改第五而丢档。
2. 拆开当前“木岛借用雷岛布尔开关”的判断。章节标题、Boss、地图、资源路径、剧情、环境声、成长改由章节配置选取，避免新岛越来越多条件分支。
3. 旧木岛玩家保留已清房间、装备、职业和剧情，不强制补打冰火岛。提供“继续现有木岛存档”和独立冰火测试入口；新的正式旅程按新顺序推进。新旧档版本、备份和一次性奖励标记一起迁移。
4. 基础成长做成表格，不按编号重复叠加。首轮预算：护盾上限 4/5/5/6/6/7，技能倍率 1.00/1.15/1.22/1.30/1.38/1.45；它们是待测试预算，不能自动视为最终平衡。
5. Tools 保留稳定场景入口，区分正式旅程、章节测试、Boss 练习。木岛名称标注第五岛，尚未实现的冰火府邸入口不要伪装成完整章节。每个章节说明是否读取正式存档。
6. 木岛暂有的返雷岛船只改为章节测试用返程；正式主线最终从木岛去府邸，回本土的主线通道在府邸结束后开启。
