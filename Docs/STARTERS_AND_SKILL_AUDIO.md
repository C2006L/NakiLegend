# 职业初始装备与技能专属音效

## 开局装备

新旅程选择弓箭手后，主武器是猎沙短弓并立即持有；选择法师后，主武器是旧木法杖并立即持有。两者的第二栏保留旅人短剑，H 可直接切刀。战士继续持短剑。

第三岛或 Boss 测试预设已有其他武器时，首次选择职业会把可保留的预设武器放进备用行囊。普通正式新开局仍按职业发放基础装备。

读取存档保留保存时的装备与当前持有栏位。旧档尚未选择职业、第二栏空着时，补发并持有对应职业武器；已有两把武器的旧档补选不替换现有装备。已经选过职业的旧档不会因更新重复发装备或强制切武器，若弓/杖在第二栏，按 H 切换即可。

## 技能声音

原先只有弱的通用释放提示。本次为八项技能分别加入释放与命中/消弹声音：

| 技能 | 释放 | 生效 |
| --- | --- | --- |
| 元气弹 | 明亮的聚光音 | 法球命中时爆散 |
| 流星 | 低沉共鸣 | 紫球命中时低音脉冲 |
| 风之刃 | 快速掠过 | 风刃命中时短促切风 |
| 护身风波 | 向外扩散 | 实际消除飞弹时反馈 |
| 雷标 | 点地锁定 | 延迟落雷判定时反馈 |
| 跃电 | 短电弧 | 首次命中与跳跃生效时反馈 |
| 根刺 | 低沉木系音 | 根刺伤害与束缚判定时反馈 |
| 孢种 | 轻脆的种子音 | 追踪孢种命中时反馈 |

技能弹体带有自己的音效标记，实际碰撞时调用对应的命中声音，避免使用当前持有的剑来决定法球声音。技能命中不会同时冒出普通剑的金属撞击声。

播放分为 8 路普通音效、4 路技能音效和 2 路重要危险提示。保留同类短间隔限制，避免追踪球、连锁命中和多颗飞弹同时爆响。技能冷却、没蓝或没有目标导致没有成功施法时，不播放完整技能声音。

素材基于 JaggedStone 的 [Magic Spell SFX](https://opengameart.org/content/magic-spell-sfx)，作者以 CC0 发布；进行裁切、调速、滤波及响度处理。48 个变体和来源记录保存在 Assets/NakiPrototype/Resources/NakiSkills。生成脚本：Tools/build_skill_audio.py。

## 测试

停止 Play 等待编译，继续存档；用 L、U、I 测试已学技能，第二/三岛可 T 配置。职业初始持有可在新旅程或 Boss 练习中测试，正式旧档无需重开。技能音效沿用 F10 的战斗音效音量。

独立试听：Art/SkillAudio/skills-cast-and-impact.wav，每两秒一组，顺序为元气弹、流星、风刃、风波、雷标、跃电、根刺、孢种。

验证覆盖新职业主副武器、H 切刀、旧档装备保护、48 份技能音效导入、法球携带正确命中标签、实际弹体碰撞播放，以及现有三岛回归。已认可的配乐和刀剑资源文件保持逐字节一致。
