# 五岛主线与结尾流程核对

已逐岛核对任务条件、Boss 后收尾、CG、天赋、航程入口，以及待播放 CG 的读档恢复。此轮不重置任何通关进度，不把已完成房间重新刷成战斗房。

## 主线顺序与结尾操作

| 岛屿 | Boss 后还需要完成 | CG 触发点 | 完成后的去向 |
| --- | --- | --- | --- |
| 沙漠岛 | 进入归渠水道，清两处沙堆、修轮机、开分水总闸并清理检修庭院 | 在望台风铃处迎接初雨，经过对白播放《甘泽归沙》 | 选天赋，望台西侧风铃乘船去雷雨高原 |
| 雷雨高原 | 沿山路风铃返回山口灯棚；引雷节点和巡路员属于此前任务 | 与灯匠交谈，播放《灯下有归人》 | 选天赋，左侧码头前往冰港 |
| 霜潮群岛 | 救出破冰队，寻回冰石；到回流闸室复位东西绞盘并开启总闸 | 总闸操作带你回冰港，再点亮归航灯，播放《潮声穿过长夜》 | 选天赋，右侧码头确认前往赤炉群岛 |
| 赤炉群岛 | 熔龟之后清理两段撤离路并接应居民、物资，回黑砂码头 | 点燃左侧公共炉灶，播放《炉火重新升起》 | 选天赋，右侧码头确认前往青栖林海 |
| 青栖林海 | 解救采种人并调查至少两处线索；古树之后沿小径回旧种床，栽种，再返回码头 | 将林册交还阿苓，播放《旧叶落处，新芽有声》 | 选天赋；当前第五岛完成，第六岛尚未开放，可确认回访火岛 |

打败最终 Boss 通常只取回元素，并不直接触发岛屿结尾。收尾任务让水、潮汐、炉火和森林重新回到居民生活中，完成这一段后再进入 CG 与天赋。

## 本次修补

- 删除雷雨港口旧的“森林试航”交互，避免误跳过冰岛和火岛。独立森林测试仍通过 Tools 的第五岛入口进行。
- 冰港只有在总闸真正开启、队伍已营救、归航灯已带回后，才显示点灯交互，避免看得到入口却按 F 无反应。
- 冰岛如果缺少救援条件，任务提示优先要求返回受困营地，避免只叫玩家反复转闸。
- 火岛撤离已完成时，地心避难站的阿铎提供“随撤离队返回黑砂码头”，不必再下楼绕行。最后一间归岸石廊原有返港操作保留。
- 如果仍选择第二层降温炉台返港，完成撤离后的对白会指向公共炉灶，不再说山里的任务还没结束。
- 森林栽种后明确提示再次按 F 返回码头；种床与最终庭院的快捷交互有落点标记。
- 收尾任务补充金色出口箭头、楼梯与交互点标记；路径计算可跨楼层，已完成的森林不再显示通往未开放后续章节的目标。

## 如何查看更新

停止 Unity Play，等待重新编译后继续原安全存档。当前已清房和任务物保留。无需重打火岛或前几座岛。

如果你停在截图中的地心避难站，并且目标为“回到黑砂码头 · 点燃公共炉灶”，更新后直接靠近房间里的阿铎按 F，即可返港；到公共炉灶再次按 F 播放 CG。

完成末尾仪式后，CG 先播放，退出 CG 后再弹出天赋选择。冰岛和森林保存的待播 CG，读档后会继续显示；返航上一岛仍使用明确确认菜单。
