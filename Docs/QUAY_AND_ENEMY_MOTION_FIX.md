# 岸线碰撞、观雨台与攻击动作修正

## 这次改了什么

冰港截图中的问题来自港口仅用一块矩形阻挡下半幅海面，而画面右侧岸线提前转折，仍允许玩家踏入弯岸外的水面。现把雷雨、冰岛、火岛和森林的港口改为明确的岸上通行区、实际栈桥与出口连接；海域和建筑边缘由这些区域的补集阻挡。东西出口提高到画面实际道路的高度。南侧相邻房间从现有栈桥前段切换，不再要求玩家走过栈桥尽头的海水。

沙漠尾声观雨台重做为完整的雨后临水码头：砂岩平台、湿石地、回流出水口、中央木栈桥、桥边浮船、岸边铜铃。替换旧的细长渠条、地面船和临时路牌。既有西侧与南侧房间连接保留；南向木桥可以返回检修庭院。F 在铜铃岸边打开全域航图；G 仍可在安全时选目的地。水渠修复 → 初雨 CG → 天赋的原有顺序保留。

怪物攻击抽搐有两项已定位原因：冲锋使用按轴滑移，可能滑进只能阻挡子弹的高物件投影，下一帧又被安全寻路拉出；冲锋和收招中的朝向还会追着玩家翻转。现在普通敌人的移动与恢复使用一致的通行判定，十处冲锋分支使用小步长直线碰撞检测，撞到障碍立即停下并进入收招。整个攻击承诺期锁定攻击朝向，接近正上／正下的微小横向变化保留原朝向。

## 怎样检查

停止 Play，等 Unity 编译完成，再继续原存档。旧港口存档中的水边位置会由原有安全落脚机制移到附近干地，不重置岛屿或任务。

- 冰岛码头：沿右侧弯岸走动和闪避，不能进入海面；沿抬高的东侧道路仍可正常换房。
- 沙漠观雨台：继续已完成水渠的存档，查看新画面；栈桥两侧是水，中央木桥可行走，船浮在桥右侧。
- 冲锋敌人：在树桩、石柱和墙边引诱冲锋，撞停后应有收招，不应贴墙左右抖动；绕到攻击者另一侧，当前攻击方向保持锁定。

本轮未重做所有敌人的逐帧美术。修正的是导航位移、撞停和朝向逻辑；攻击的实际视觉手感仍欢迎继续反馈。
