# 青栖林海 D1：怪物、Boss、技能与武器

状态：设计参数，尚未实装。以 V16 高原完成时的常见装备进入，禁止要求玩家已经拥有尚未制作的火岛技能。

## 十类普通怪

下列生命是第一轮测试预算，不按同一百分比全体加血；读招和组合是主要区别。新增类型分三层逐步引入，每房使用 2～3 类，最多 4 类。

| 类型 / 生命 | 外形辨识 | 行为与预警 | 应对与限制 |
| --- | --- | --- | --- |
| 针尾蜂 / 38 | 黄黑腹部、长白针，离地阴影 | 悬停 0.7 秒后沿锁定方向射三根细针 | 横移或风波消针；不能边追踪边连续射 |
| 棘甲虫 / 80 | 宽褐壳、正面木盾、侧腹浅绿 | 正面减伤，先抬壳 0.8 秒再短距顶撞 | 绕侧、背击；减伤不低于原伤害 50%，不能全免 |
| 裂荚株 / 52 | 三瓣果荚、扎根不动 | 果荚变白 0.9 秒后扇射五粒种子 | 借掩体靠近；固定射程，不隔墙索敌 |
| 匍藤猎手 / 62 | 低伏红叶、前肢长根 | 路径亮线 0.85 秒后扑到旧位置 | 错身反击；移动路径受墙和门约束 |
| 灰孢团 / 36 | 灰帽白点、橙色毒区边缘 | 膨胀 1 秒，吐一片短时孢雾 | 打断或退出；死亡不无预警爆毒 |
| 苔背盾卫 / 100 | 朽木甲、露出的菌核 | 先驻盾，间隔敲地两次 | 第二下错时，盾后明显发亮；可用根刺定住绕背 |
| 腐叶蜈 / 64 | 分节红腹、钻地土屑 | 地面连续拱起 1 秒后出土，直线穿刺 | 不能钻到门口和玩家脚下立即伤害 |
| 吞苔蛙 / 70 | 鼓颊青蛙、宽足 | 0.9 秒落点圈，跃落留下小片湿苔 | 湿苔只轻缓速，不叠加定身；不与毒区全覆盖 |
| 引荧螟 / 44 | 蓝白灯囊、圆翅 | 给最近一名同伴短时护壳，连线可见 | 优先击破；每只最多一目标，不互相护持 |
| 寄枝鹿 / 96 | 折枝角、胸前紫菌结 | 分两拍踏蹄，1 秒后短冲 | 冲锋后侧身喘息；单房最多一只，避免与蜈同时夹门 |

第一层引入前五类，第二层再引入盾卫、蜈、蛙，第三层加入引荧螟与寄枝鹿。所有普通怪第一击至少留 0.55 秒可见前摇；普通命中伤害预算 1～1.5，重冲撞 2。不能靠视野外攻击提升难度。

## 四类精英

| 精英 | 组合变化 | 房间约束 |
| --- | --- | --- |
| 金针蜂后 | 两次错时针阵，第二次方向预先锁定 | 最多配两只甲虫，不同时配裂荚株封满弹道 |
| 空心苔卫 | 破壳后放出两只小孢团，仍用一次性生命预算 | 小怪不重复给精英掉落，最多一次召唤 |
| 绞根猎手 | 一次扑击后拉出两条交错根线 | 两条线之间至少留玩家加闪避余量的通道 |
| 夜灯寄枝鹿 | 同伴护壳仅维持 3 秒，冲锋末尾失去护壳 | 每波只出现一个精英，倒地继承活体尺度 |

精英默认普通生命约 1.4 倍，奖励 20 元素，增加行为而不同时加速所有前摇。精英符号用金色断环；敌方毒区为橙褐虚线边界，玩家木技能为青绿实线，兼顾非颜色辨识。

## 三场 Boss

| Boss / 生命预算 | 第一阶段 | 第二阶段与机会 |
| --- | --- | --- |
| 棘甲母虫 / 560 | 抬甲冲撞、左右分叉种子、召两幼虫 | 50% 后冲锋回摆一次，预先显示回程；撞木桩露腹 1.4 秒。场上幼虫上限 2 |
| 菌冠孢囊 / 900 | 三个外囊轮流张开喷孢、顺时针腐根、单点落孢 | 45% 后两外囊错时喷，先后至少差 0.65 秒；打破外囊取消对应招式，持续露核 1.6 秒 |
| 古树守望者 / 1700 | 锁点根刺、沿边缘爬行的根浪、抬臂落枝 | 45% 后根浪与单次落枝组合，预警不同；每轮过度生长后根结露出，打断三次后剥离木石 |

三个 Boss 都有 0.9 秒以上重招预警，伤害预算 2，主要落点不连着追玩家。古树第三次破结后结束，不要求清零血再额外打一条隐藏血条；生命条显示结点阶段与剩余结数。守望者幸存、禁止给贤者之石充能。

Boss 战中至少 35% 可走面积无毒区，任何时刻保留通向安全扇区的路径。破结、转阶段和结束时清理残弹与危险圈。零耗武器也能完成破结，木技能不能成为必需钥匙。

## 木技能与状态

| 技能 | 元素消耗 / CD | 作用、视觉与边界 |
| --- | --- | --- |
| 根刺 | 7 / 1.6 秒 | 母虫后学习，自动锁定可见敌人，在其旧位置抬起三段根尖，总伤害 24，普通怪束缚 0.6 秒；Boss 只短暂减速，不能无限控 |
| 青芽护息 | 12 / 6 秒 | 第二层救人后学，一圈疏叶绕身 2 秒，解除一次孢毒并减少 25% 后续孢毒伤害；不直接回血或生成无限护盾 |
| 孢种 | 9 / 2.4 秒 | 支线林册可学，短弧投种、落地开浅绿花纹；命中 12 + 4 秒共 16 持续伤害，同一目标最多三层，同源刷新而非无限叠加 |

L 继续保留光 / 暗，U / I 仍为两个可换元素槽，木与风雷技能共同竞争装备位置，不新增一排常驻卡片。缺少技能的玩家可在本层休憩点补学，教学对白不讲房间计数。

敌方孢毒：3 秒内最多三次小额跳伤，建议每次 0.4，每次进入有 0.5 秒宽限；离开后很快解除，重新进入不重叠多个环境 DOT。不得同时让血量持续扣减、屏幕全绿、人物硬直。用脚边小叶图标和简短音效提示，不遮挡视线。

元素关系先仅测试明确场景：风波可吹散一片普通孢雾，木根束缚可打断高原冲锋；火对木 1.25 倍仅在提供可得火源时启用。毒对腐解怪效果减半但至少保留直接伤害。正式全元素克制表须统一设计，不能直接把这些局部提案写进现有运行规则。

## 攻击美术制作约束

长矛的亮线与枪尖运动一致，弩有弩矢和弦的方向，木杖用种子而非复用光球。特效只在有效命中窗口最亮，玩家效果与危险区边线不同。先制作静止、前摇、命中、收招的可读样例，再扩动画；不可把武器贴图悬在手外。
