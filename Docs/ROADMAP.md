# 下一阶段：沙漠岛可玩短流程

目标是做出一段约 5–10 分钟、从进入房间到打败 Boss、获得风元素碎片的完整体验。每一步都提供 Unity 可试玩版本，再继续扩大内容。

## 1. 小怪形象与战斗反馈（下一项）

给沙蝎与持矛骷髅补齐统一风格的移动、攻击前摇、出手、受击、死亡动作。动作素材先检查脚步与武器姿势，再接入判定；左右可复用镜像动作，避免生成出两套质量不同的循环。

补上生命条、命中闪白、简短受击反馈、基础音效，并让敌人攻击预警与实际出手对应。角色与敌人、柱子的前后遮挡要稳定。

验收：玩家能看懂两种敌人的攻击、能通过走位或闪避避开；连续战斗和重开不出现残片、动作卡住或错误朝向。

## 2. 房间与地图流程

保留沙漠地图的视觉方向，将地面边界、柱子、门和敌人出生点做成可编辑配置，逐步从单个原型脚本拆到角色、敌人、战斗和房间模块。先搭建 3–5 个相连房间，包括普通战斗、奖励／恢复和 Boss 房。

门在战斗时关闭，清怪后开启；穿门能进入下一间，玩家生命和能量能延续。先用固定布局验证流程，再增加随机组合。

验收：从入口走到 Boss 房可重复完成，房间切换不重复生成玩家、敌人或 UI，也不会卡在门框和柱子上。

## 3. 风蝎 Boss 与战利品

制作正式风蝎形象，优先实现两到三种清晰攻击和一个低血量阶段。将攻击前摇、弹幕、冲刺和伤害判定对齐；确认剑击和法球都有参与战斗的价值后，再集中调整伤害、耗能和冷却。

击败后掉落风元素碎片，显示完成提示，并解锁一种风技能用于试用。

验收：Boss 可稳定击败，失败和重试正常，碎片只领取一次，技能解锁立即可测试。

## 4. 剧情呈现与第一岛闭环

加入国王命令的简短开场、Boss 击败 CG 和碎片获得对话。先把高精度插画接到对话与 CG 界面，再扩展到其他岛屿和光暗剧情。

验收：新玩家无需开发者解释即可理解目标、操作、过关条件，并完成第一岛。此后再确定存档、武器切换和下一座岛的优先级。
