# 暮钟岛首领与掩体修正

本轮加强已实装的誓庭卫长，血量保持 6,120。

- 五招循环：冲锋配合延迟掩护齐射；近身横扫带扇形弹；落地震击（后期三处）；举盾推进；环形弹接连续扇射。
- 环形弹随三个阶段为 14／18／22 颗，连续扇射为 2／3／4 轮，每轮间隔 0.24 秒；弹道保持间隙。普通子弹不加轨迹预警，冲锋和落点保留提示。
- 举盾仅持续 1.5 秒，正面挡弹，侧后方与近战仍可进攻；阶段援军由两名调整为三名。后期缩短招式间隔，保留收招时间。
- 森林树冠和透明边不再阻挡行走，实体改为内部树干／倒木足迹；府邸残柱缩小碰撞，并将挡弹范围与行走范围统一。
- 航图、层区标题和章节状态统一为：鸣沙洲、雷雨高原、霜潮群岛、赤炉群岛、青栖林海、暮钟岛。府邸仍是岛内建筑名称；存档文件名和岛屿编号不变。
