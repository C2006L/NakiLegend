# 大骑士府邸：归功外庭 V2

本轮实现第 1 层的完整试玩环线；断粮旧村、淬炼工坊、无昼内庭和大骑士最终结局仍待制作。外庭首领是誓庭卫长，不是大骑士本人。后续继续读取府邸独立存档。

## 如何开始

- 原有旅程：清理当前房间、关闭对话后按 **G**，选择“大骑士府邸 · 外庭试玩”，选“继续当地安全点”或“1 归功外庭”，确认出发。原有装备、职业、天赋、光之力/贤者之石和元素技能配置随身携带。
- 直接试玩：停止 Play，使用 **Tools → Naki Legend → Play → 6 Manor Courtyard Adventure**，再按 Play。独立场景使用测试起始装备；想带自己的装备请通过 G 航图进入。
- 练首领：**Tools → Naki Legend → Boss Practice → 6 Oath Captain**。练习不覆盖旅程存档。
- **F5** 清房后保存、**F9** 读取；**R** 回到本岛安全点。不会清除前五岛存档。通行印、调查、已领取补给和地面装备都保存。

## 关卡结构

渡口只有东侧陆路出口；南侧木栈桥只用于登船。庭院采用真正相邻的四向门，沿两条支路绕回主路。

| 石狮夹道 | 巡卫、弩手、盾卫、猎犬等组合 |
| 勇者纪念庭 | 调查旧石像；发现五岛航线与旧勇者的相似之处 |
| 钟廊巡路 | 箭手、重兵与游走单位混合 |
| 废弩塔 | 四波精英据点；外庭通行印之一 |
| 旧马厩 | 猎犬与远程单位配合 |
| 退役营房 | 一次性整备；粮道图与行路记录 |
| 受封登记处 | 调查旧委任书，核对王印 |
| 封粮门道 | 盾兵与重兵配合 |
| 誓庭前室 | 一次性战前整备；未满足条件时首领门封锁 |

调查石像、委任书并清理废弩塔、断旗台，才能开启卫长房。普通战斗房 3 波、每波 5 名；精英房 4 波、每波 6 名。混编按房间与波次改变，不使用沙漠或雷雨单位占位。保留掩体和门口安全抵达空间。

## 敌人

| 类型 | 进攻与应对 |
|---|---|
| 暮钟巡卫 | 追击后挥剑；趁收招反击 |
| 誓庭盾卫 | 守住阵地、近身挥斩；绕到侧面，正面投射物减伤 |
| 钟楼弩手 | 换位后窄角三连弩矢；无弹道预警线 |
| 断链猎犬 | 前截、锁定方向再扑击；同时准备扑击最多两只 |
| 誓录官 | 可打断的护阵，只保护附近最多两名非首领盟友，不给 Boss 回血 |
| 断旗斧骑士 | 约 0.72 秒抬斧，较宽近身横扫；无通用法球 |
| 沉誓锤骑士 | 约 0.95 秒抬锤，地面圆形震击，约 1 秒收招 |
| 暗黑祭师 | 单次一颗深紫色烟陨，落点圈后约 1.25 秒落地；两次施法相隔约 12 秒。抬手可打断，死亡清除未落地陨石 |
| 长廊弓箭手 | 明确拉弓动作与三箭散射，保持距离、换位 |
| 暮庭暗黑法师 | 不规则游走，释放四颗深紫烟尾法球；与祭师的落点攻击区分 |

常规敌人生命 145–470，伤害使用府邸倍率 1.75；数量适中，靠不同射程和进攻节奏形成难度。数值为试玩起点，尚不代表实际玩家通关体验已经验证。

卫长最终生命 7200（不会再乘一次岛屿 Boss 生命倍率）。主动绕掩体追击，轮换破盾冲锋、长枪横扫、错时落点和枪芒齐射；70%/35% 压力阶段召集援兵，低于 1/3 生命掉落一次 40 元素补给。击败后单膝卸武，不播放死亡消散，也不提前完成整座府邸。

专属武器 **誓庭卫枪**：新稳定 ID 132，物理长矛，伤害 38、间隔 0.72 秒、射程 3.1、消耗 1 元素。新形象与独立出枪/金属命中声音；此前 0–131 的武器 ID 不变。

## 剧情与美术

开场 CG《暮钟不迎归人》使用已有府邸概念 CG；首次登岛展示，保存后继续不强制重放。纪念庭、委任书、停运粮道与卫长交谈依次铺垫上一代航行者。光路线看到被抹去的救助记录；贤者之石路线察觉同源余烬，但不会把石中剩余能量清成“一人份”。目前只埋线索，不提前揭晓大骑士身份。

本轮使用内置 **image_gen**，新增两张共 11 种角色动作图、庭院道具图、渡口底图和卫枪图。源图、提示词和音效来源见 [Art/ManorCourtyardV2/README.md](../Art/ManorCourtyardV2/README.md)。原始图保留；游戏资源在 `Assets/NakiPrototype/Resources/NakiArt/ManorCourtyardV2`。切图保留生成 alpha，同一角色所有动作采用相同格子和 PPU，防止倒地突然放大。
