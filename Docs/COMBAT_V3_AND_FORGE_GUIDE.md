# 工坊指引与弹幕战斗 V3

本轮处理工坊救援后去向不明、占位方块、闪避打断蓄力，以及远程火力不足的问题。火岛仍为两层 30 房；本轮没有开放第三层和整岛结尾 CG。

## 救出阿铎之后

工匠避难间的棕色 U 形原本是围栏占位图，现在改为有立柱、横杆的铁护栏；撤离桥头的整块棕色矩形原本是挡脚的灰槽，现在显示为有石边、灰渣的排灰沟。未放桥前不能穿越沟槽，放桥后才形成通路。

1. 救出阿铎，学会烬环。
2. 按 M 看带金色边框和 `!` 的“撤离桥”目标；清房后的金色箭头指向沿途出口。
3. 回到“撤离桥头”，靠近左侧绞盘，按 F 放下桥梁。安全房中绞盘上方也有文字标记。
4. 巨匠房解除剧情封锁，地图目标改为巨匠。打败它后前往降温炉台回港。

站到巨匠封锁门附近会提示缺少的条件，也可按 F 查看。远端“地心压力门”属于尚未开放的后续区域，已明确标注，不是漏打某只怪。工坊顶栏也已从错误的“黑砂海岸”改为“锻链工坊”。

## 弓弩与法杖

按住 J 蓄力、松开射击。K 闪避保留已有蓄力，闪避期间暂停蓄力计时；在闪避中松开 J，会等闪避结束再发射，按住则继续蓄力。换武器、受击、换房和打开菜单仍取消瞬时蓄力，防止恢复操作时误射。

满蓄弓为基础伤害的 **6 倍**，弩为 **6.5 倍**；半蓄按平方曲线增长。弓约 0.8 秒、弩约 1.1 秒满蓄，弓箭手再缩短约 13%。超过轻点区间额外消耗 1 元素，仍只射一箭。伤害还受护甲、元素克制等战斗规则影响。

所有法杖一次射出 **3 发**窄扇面小弹，各为原基础伤害的 80%，全命中总计为原来的 2.4 倍。一次扣武器原本的一份元素费用，保留各法杖的间隔和射程。小弹使用细尾迹、武器释放音；持杖待机与角色绘制不会发射或扣能量。

## 怎么查看

停止 Play，等待 Unity 编译，再 Play。火岛使用 **Tools → Naki Legend → Play → 4 Fire Islands Adventure**；配置页选继续已有进度，游戏中 F9 读最近安全点。不要选择“另起测试”或 N 新配置来接着原档玩。无需重打已清房间，已获得装备、救援和放桥标记沿用存档。

只比较巨匠弹幕可打开 **Boss Practice → 4 Forge Master**，它不写正式存档。通过旧 15 房存档升级、30 房存取和冰火往返验证；本轮不改变存档结构。

新增美术使用内置 ImageGen，资产为 `Assets/NakiPrototype/Resources/NakiArt/FireWorkshop/readability-v2.png`，提示词及切图记录见 [美术记录](../Art/FireWorkshop/readability-v2-prompts.json)。原生验证与实际截图见 [验证记录](../Validation/CombatV3/README.md)。
