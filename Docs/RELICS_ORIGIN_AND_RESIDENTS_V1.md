# NPC、首领专武与光暗成长：本轮实现与试玩

本轮更新现有五座岛：沙漠、雷雨高原、霜潮群岛、赤炉群岛、青栖林海。第六岛大骑士府邸、回王国与终局尚未制作；后续衔接另见 MANOR_ORIGIN_ENDING_PLAN.md。

## 怎么查看

1. 退出 Unity 的 Play，等脚本和图片导入完成，再运行。已同步到你目前使用的工程，没有替换本地场景或清除存档。
2. Tools → Naki Legend → Play → 4 Fire Islands Adventure → 继续火岛存档，可以继续原来的火岛进度。第三层灰烬撤离道与归岸石廊是本轮避难间改动的位置。进入未清房时居民躲在关闭的石屋里，清场后才出门；靠近按 F 接应。
3. 已完成接应的旧档会保留撤离状态，不会把居民重新刷出来。要重看营救可另起第三层测试；重开操作会备份原存档。
4. 任何正式首领或守关者击败后，地上有对应专武，清泉药剂直接加入行囊。F 拾取；背包满仍可选择任意携带或备用格替换。Boss Practice 为独立练习，不发放正式专武奖励。
5. 安全房按 B 打开行囊，点击“主属性战技”选择已领悟的光／暗技能，选好后按 L 释放。U / I 和 T 元素技能配置仍然独立。原有职业及双武器切换继续有效。
6. F5 / F9 沿用各岛原安全存档。更新不会让已清房重新刷怪，也不会要求重新通关前两岛。旧档按已到达的岛补齐此前阶段的战技资格；本岛新剧情仍在对应安全节点触发。

## NPC 与营救场景

新增八种有职业区别的成人形象：炉匠、搬运工、医师、守港人、船队长、植物学者、林册学者、炉工。分别用于火岛港口／工坊／撤离区、雷雨安全补给点、冰岛破冰队、森林阿苓与采种人。

火岛第三层不再把老人和孩子摆在战斗人群中。入口侧设置玄武岩避难间，保留防护碰撞并预留净空，怪物出生点避开该区域。清场之后成年人从避难门前出现，接应后沿已清理的中间通道离开。第二层桥头工人也替换为搬运工与炉工。港口对白继续按救援／返港／点炉的实际进度变化。

## 普通装备与随机补给

旧 42 个武器 ID 保留；追加十个普通武器系列及十七个专武系列，每系列基础／散华／凝聚三种配置，共 123 个武器定义。这个数字包含变体，不等于 123 套完全独立的攻击动作。

| 岛屿 | 新普通系列 |
| --- | --- |
| 沙漠 | 流沙杖、驼铃短弓 |
| 雷雨 | 引雷针杖、铜簧速弩 |
| 冰岛 | 雪鸮弓、碎晶杖 |
| 火岛 | 灰烬喷杖、炉压弩 |
| 森林 | 荚果杖、藤索弩 |

补给箱为三个武器选项加一个恢复选项。按约 60% 本岛主题、25% 通用、15% 已解锁变体挑选；类别池为空时回退到可用池。同箱不会出现同一基础武器的三个变体充数，前两个选项至少是不同攻击类型。普通箱不混入首领专属武器，后续岛装备不提前出现在前岛。

散华：法杖增加弹数，弓弩增加侧矢，近战扩大覆盖与命中数；凝聚：法杖改单发重弹并穿透，弓弩提高重矢伤害及穿透，近战提高单击伤害但出手更慢。所有配置实际消耗元素之力，保留部分旧物理武器的低耗／零耗定位。

首次打开生成的选项随安全存档保存。关掉菜单重开、F9 或换房不会无限重抽同一个补给箱。恢复选项为生命 +2、护盾 +2、元素 +35；已满部分不溢出上限。

## 贤者之石与光之力

暗能不再有 100 的玩法上限；正常生物击杀 +2、精英 +3，召唤物等沿用防刷规则。储量用有限非负数保存，读档与往返旧岛继承当前实际余量，不把旧档里的较高储量补回来。

暗技能伤害倍率 = 1 + 0.2 × log₂(1 + 暗能储量 / 25)。例如 25 / 100 / 400 暗能时约为 1.20 / 1.46 / 1.82 倍，储量继续有收益，同时避免线性增长失控。

| 主属性战技 | 消耗 | 冷却 | 作用 |
| --- | --- | --- | --- |
| 元气弹 | 6 光能 | 1.2 秒 | 五颗追踪光弹 |
| 守心光幕 | 18 光能 | 5 秒 | 1.5 秒内承受伤害降至 30%；真实受击时返还少量光能，有内置间隔 |
| 聚日 | 24 光能 | 4 秒 | 五颗更强的追踪穿透光弹 |
| 流星 | 1 暗能 | 0.8 秒 | 五颗追踪紫球，每颗基础伤害 20，再受储量和岛屿成长影响 |
| 紫曜贯虹 | 8 暗能 | 4.5 秒 | 自动选方向的短时激光，受实际掩体阻挡 |
| 星陨 | 21 暗能 | 1.2 秒 | 五颗更大的强化追踪球，基础流星的 1.5 倍伤害 |

暗流星／星陨最多并存三组，避免无限累积弹体；完全受墙阻挡、技能无法产生弹体时不扣资源。光技能仍自然回能，元素技能继续使用独立元素槽。切换主战技共享剩余冷却，不能通过换技能重置 CD。

## 光暗剧情贯穿五岛

沙漠的碑文／井沿微光或异乡归途残响，雷岛的破灯与旧巡路簿，冰岛的归航记录与另一名披斗篷的旅人，火岛的炉匠刻记与王室封蜡，森林的新芽与府邸徽记，会在安全节点依次补足两条路线。

雷岛阶段领悟第一项进阶主战技，火岛阶段领悟第二项。故事以眼前的人、自然环境和遗物呈现，不使用“过三间房即可学习”这样的剧情台词。不会在森林提前说破大骑士身份。

“战斗残响可积攒施法”和“完整灵魂携带人格与契约”目前作为故事伏笔区分。没有在当前五岛强行扣空暗能，亦没有把未完成的第六岛结局伪装成已实现。
