# 雷岛铜卫修正与暮钟岛施工进度

## 雷雨高原修正

守路铜卫原来在攻击之后几乎没有接近玩家的时间，远距离招式选择又会重复近身横扫，导致站桩。现在远距离选择突刺，突刺带真实位移；近身选择横扫，中距离使用弹幕。突刺前完整显示路径，冲刺沿锁定方向进行，遇障碍撞停。铜卫移动速度由 0.85 提至 1.8，攻击后保留追击空档。

扇形弹幕由 5／7 发提高到 7／11 发基础数量，再沿用现有扇形密度规则。70% 与 35% 转阶段各呼叫两名错峰援军，分别延迟 1.5 与 2.1 秒到场，不反复触发，并遵守人数上限与避开玩家脚下的生成规则。原有三分之一血量 40 元素补给保留。

雷岛掩体不再使用 `thunderRock ?? journeyRock` 的沙漠回退。缓存为空时直接重新加载雷雨素材，缺少资源时报告明确错误。原生检查遍历了正式雷雨 39 个房间的渲染物件，未使用沙漠石头与砂岩石柱纹理。若仍遇到外观不合主题的物件，可根据房间名继续定位。

停止 Play，等待导入编译后继续现有存档。已完成房间、CG 与装备保留；未完成铜卫战按原来的安全点继续，或从 Boss Practice 测试。
