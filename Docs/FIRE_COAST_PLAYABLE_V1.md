## 如何进入

先停止 Unity 的 Play，等待编译完成。

- 接着冰岛存档玩：Tools → Naki Legend → Play → **3 Frost Tide Adventure**，点击 Play 继续冰岛。完成冰岛总闸与灯塔 CG 后，在冰港的登船点按 F，选择“乘船前往赤炉岛 · 第一层”。继承职业、光暗选择及能量、两把携带武器、储备、药剂、已学冰雷风技能与强化。无需重新打冰岛。
- 直接测试火岛：Tools → Naki Legend → Play → **4 Fire Coast First Layer**。配置页有光／暗选择；有火岛存档时 F 继续，否则 F 开始。独立配置提供冰技能和 7 护盾，便于测试冰克火。
- 只练习首领：Tools → Naki Legend → Boss Practice → **4 Red Spine Lizard**。此模式不写正式旅程存档。

实际场景为 `Assets/Scenes/NakiFireCoast.unity` 与 `Assets/Scenes/NakiFireBossPractice.unity`。若已打开旧场景，Tools 会打开新场景，不需要往 Hierarchy 再添加脚本。

## 这一层怎么玩

黑砂码头 → 沿灰砂路探索 → 清理避难所看守并转动绞盘 → 寻找赤脊熔蜥 → 击败首领 → 东侧安全训练炉学习火种 → 返回港口。支路包含旧炉匠的信、装备与休息点。地图沿门行走换房，M 仅查看，不传送。

这不是寻回火石的最终战。熔蜥退回温热岩洞，居民可以沿安全炉道撤离；更深的工坊尚未开放。不会在第一位首领后提前播放整岛结局。

J 攻击；弓弩按住蓄力、松开发射，H 切换近战备用武器。K 闪避；L 是光／暗主技能；U／I 是两项元素技能；T 配置；F 交互；B 行囊。火种学会后默认装备在 I，可以在 T 中更换。

## 新敌人和首领

| 单位 | 行为与应对 |
|---|---|
| 灰砂短刃客 | 接近后锁定短刺线，前摇可绕开 |
| 炉鳞蜥 | 熔壳减伤、三枚慢速扇射；冰能快速冷裂熔壳 |
| 灰翼蝠 | 明确直线预警后短扑，扑完暂歇 |
| 煤袋投手 | 煤包在旧落点延迟爆炸，走开或攻击煤包拆除 |
| 赤脊熔蜥 | 锁向冲扑、9 发扇射和延迟熔爆；半血后 13 发与错时煤包，仍有前摇及收招 |

冰攻击有 1.3 倍克制伤害，并逐片破除熔壳；普通武器也能积累破壳，破壳后有 1.3 秒反击窗口。半血仅重建一次有限熔壳。煤包最多同时三枚，无灵魂和额外掉落，不能拆包刷暗能。

普通战斗房 3 波，每波 3–4 只；精英房 4 波。增援至少 1.2 秒预警，每批最多两名投手。新增独立敌人插图与黑砂海港、玄武岩地面、火山岩障碍、避难所营门和训练炉；敌人当前为单主体像素图，移动辅以位移与浮动，尚不是整套逐帧动作。

## 能量、装备和存档

护盾上限保底 7，技能基础系数 1.30；继承时不叠加章节护盾。光／暗与元素分别计算，火种只用元素：基础伤害 22、6 元素、CD 1.2 秒。命中后短燃烧，刷新持续时间，不无限叠层；持续伤害不会再次触发自身。

新增赤炉短剑、余烬长矛、煤星手弩、守炉法杖，ID 18–21，使用现有武器轮廓和火属性色调。旧的冰武器仍能正确读取。普通清房提供 30 元素结晶、精英 40；首次休息点补 2 生命与 40 元素。掉落与拾取仍遵守已有资源规则，不补错误的主属性能量。

火岛独立使用 `fire-chapter-v1.json` 与 `.bak`；清房和事件后自动保存，F5 安全保存、F9 读取。战斗中不覆盖上一个安全点。火岛返船会读取冰岛自己的进度，再次登船则读取火岛自己的进度。各岛返程按本岛历史存档恢复，并非把后岛装备反写进旧岛。Boss 练习不覆盖正式存档。

配乐和刀剑声音沿用已认可版本；火种使用已有短促火焰音色，未更换乐曲文件。
