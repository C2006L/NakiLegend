# 五岛敌人与 Boss 难度调整

本轮加强现有五座可玩岛屿，延后大骑士府邸实现。敌方单次基础伤害维持原值，压力主要来自血量、分批援军、战术攻击空档与阶段追击。前摇和刷怪预警保留，已清理房间不会重刷。

## 刷怪与战斗节奏

普通与精英战斗每波的战术同伴由原先第一岛 1、后续 2，改为第一岛教学阶段 1、之后 2，其余岛 3，火岛与森林第三层为 4。额外同伴优先使用侧翼近战，不继续堆叠治疗者、狙击者和法师。

同一波只注入一次。援军有至少 1.4 秒预警并错开到场，同屏达到上限时继续排队；位置靠近玩家时换点并重新预警。前几间鸣沙洲房间保留原有节奏，不提前交叠下一波。

常规攻击的预警不缩短，只缩短预警之后的调度空档。护阵与狙击专职的攻击后等待同步略缩短。现有冲锋撞停、方向锁定、同屏施法数量约束、掩体和援军批次上限保留。

## Boss

70% 与 35% 阶段切换、辅助怪的一次性生成与三分之一血的 40 元素补给均保留。后四岛阶段追击由 3／5 发提升至 5／7 发，追击预警仍为 0.8 秒；第一岛上一版已经是 5／7 发，本轮保持这组数量，主要通过血量与空档加强。

追击最短调度间隔从 3.2 秒变为五岛分别 2.9／2.8／2.7／2.6／2.5 秒；实际仍受 Boss 完成攻击与最多两组排队追击限制，不会按计时器无限发射。机关类 Boss 继续保留各自专门行为，同时获得新的生命预算。
