# V15：府邸裁切、掩体、收招压制与技能实用性

## 实施内容

- 府邸两个后续首领不再按等宽格子直接切图。逐行提取独立连通轮廓，保留伸出原格子的剑尖，并剔除相邻动作的武器。各帧保留原像素比例和脚底锚点，纹理四周留透明边。
- 府邸柱子分开使用脚底行走碰撞与柱身挡弹区域。持续激光、线形机关和玩家光束按实际发射位置计算首个遮挡接触点；光束画面与伤害共用截断后的路径。遮挡发射者与枪口之间时，不允许光束从柱后凭空出现。
- 静态石柱、府邸、冰晶、雷岛石块、锻炉与火山掩体收紧脚底轮廓；这些脚底以及林海天然掩体、可破坏物采用圆角碰撞。门、围栏、岸线保持原本边界。移动以不超过 0.1 世界单位的子步检测，先尝试完整移动，再尝试沿轴滑动。
- 第五、第六章的首领房在通道、房间边界及现有掩体间距允许时，尝试额外摆放三处掩体；早期章节仍额外一处。保留通行空间，位置不足时减少数量。
- 首领收招期间实际受到伤害，会获得至少 0.32 秒的重整时间，浮字显示“受压制 · 重整架势”。单次收招额外延长最多 1.2 秒。首领仍缓慢调整位置，攻击阶段仍能行动；已发出的子弹不删除、不召回，小怪不参与此收招机制。

## 首领攻击阶段

17 组组合招式增加一拍齐射；中途第三拍重新瞄准一次，之后每颗弹丸仍按固定方向飞行。环形弹幕略增数量并保留缺口；扇形组合末拍增加一组较慢的侧翼五连弹。持续激光从 2.4 秒延长到 3 秒，扫动型角速度从 18 提至 22 度/秒。弹速和生命值不增加。组合招式完成后再进入收招，避免打断招式或突然清弹。

认可的誓庭卫长不加入这些组合增益，继续保留原有攻击基准。
