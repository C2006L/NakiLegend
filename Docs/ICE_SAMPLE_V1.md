# 第三岛：冰港三房可玩样板

本次推进到冰山岛的首个战斗样板：冰港码头、冰封回廊、裂冰甲兽的晶甲庭。它不代表完整三层冰山岛已经完成，也没有提前播放冰石回收和海湾解冻的最终 CG。原沙漠、雷岛、第五岛森林及其存档继续保留。

## 如何打开

1. 在 Unity 停止 Play，等待脚本编译完成。
2. 打开 **Tools → Naki Legend → Play → 3 Ice Harbor Sample**，再点击 Play。
3. 配置页按 **1 / 2** 选择光之力或贤者之石，按 **F** 开始或继续已有冰港存档。选择战斗专长后即可行动。
4. 想直接试 Boss 和冰技能，使用 **Tools → Naki Legend → Boss Practice → 3 Ice Beast**。练习初始开放雷标、跃电、冰锥和霜环，按 T 配置 U / I。

场景分别为 `Assets/Scenes/NakiIceSample.unity` 和 `NakiIceBossPractice.unity`。不要用旧水渠样板场景测试冰岛。

完整雷岛已有的结束流程保持原样。完成“灯下有归人”后，在灯棚北侧的小船处按 F，也能前往冰港。进入已有冰港进度时继续该岛安全点；第一次到达则继承当前专长、双武器和备用装备、补给、光暗分支、主属性储量与武器强化。冰岛的技能成长倍率为 1.22，基础护盾上限为 5，不修改原场景的基础护盾参数。

## 体验路线

- **码头**：船夫说明航行；与持灯的守塔人交谈，得知破冰队沿东侧回廊失联。覆雪小船用于返回雷雨高原。
- **回廊**：沿东门进入，三波敌人从晶甲守卫逐步加入浮冰晶灵。怪物出现前有地面提示，清房后开门并自动保存。
- **晶甲庭**：再向东遇到裂冰甲兽。雷击可击碎晶甲，带来短暂输出空隙。普通武器也能打，不强制携带雷武器。
- **记录**：甲兽退入冰雾后，调查左上方的破冰队记录，学会冰锥与霜环。沿右下方路牌返回码头，交给守塔人，结束本样板的调查。

主线这里没有取得最终冰元素碎片。后续三层扩展才会推进到极夜晶庭、潮门与破冰队返港。记录中箭头指向的深处暂未开放。

## 战斗规则

| 内容 | 当前行为 |
| --- | --- |
| 晶甲守卫 | 82 生命，两片晶甲；靠近后锁定方向、预警，再做冰斧突刺。属于有灵生物，可为贤者之石充能 |
| 浮冰晶灵 | 56 生命，无晶甲；保持距离后释放三枚扇形碎冰。冰晶构造物不提供灵魂 |
| 裂冰甲兽 | 780 生命，四片晶甲；轮换晶角冲锋、碎冰扇射、锁定旧落点的霜裂；半血暂停后再生三片甲，扇射和进攻节奏增强 |
| 晶甲 | 还在时减伤 35%；每次雷元素命中削去一片，最后一片破裂会打断动作并产生约一秒恢复窗口；雷克冰 ×1.3 仍成立 |
| 冰锥 | 6 基础元素消耗，1.4 秒冷却；自动选择可见目标后沿直线飞行，命中减速 1.5 秒；Boss 减速时间更短 |
| 霜环 | 12 基础元素消耗，5 秒冷却；作用于身边约三格范围，造成冰伤并减速；Boss 的持续时间与减速幅度受限 |

冰锥和霜环随章节技能倍率成长，法师元素消耗优惠继续生效。它们消耗元素之力，L 的元气弹或流星仍使用独立光暗资源。清房后 T 可配置 U / I；战斗中只能查看，不能刷新冷却或换技能。

所有伤害都发生在蓄力之后；冲锋与落点在蓄力时锁定，不追着玩家瞬移。冰块的脚部阻挡移动，较高的晶体部分同时阻挡飞弹。门口与交互点留出通行区域。

## 存档与测试

冰港使用 `Application.persistentDataPath/NakiLegend/ice-sample-v1.json`，不会占用雷岛、森林或未来完整冰山岛的存档文件。清房、击退甲兽、学会冰技能及交回记录后自动保存；F5 安全时手动保存，F9 读取。战斗中不覆盖上一个安全点。损坏的主文件会尝试恢复 `.bak`。

存档包含三房探索状态、已学冰技能、U / I 配置、各技能冷却、装备、资源和调查进度。“另开冰港旅程”会先确认，并为原文件保留历史副本。Boss 练习不写旅程存档。

本轮没有改变旧岛的存档路径，也没有要求已完成森林的玩家补打冰港。雷岛、冰港各自保留安全点；返回雷岛读取原岛进度，不把样板取得的物品强行覆盖回旧岛。

## 当前美术与声音范围

新增冰雪地面图、晶甲守卫、浮冰晶灵、裂冰甲兽、守塔人、冰晶掩体、记录架、覆雪小船和信号晶柱素材。信号晶柱预留后续机关，本样板尚未布置。角色主体仍沿用已有可动画勇者。

新敌人当前使用独立静态精灵、朝向翻转、移动起伏和动作预警，尚未制作完整多帧步行动画。墙体与门暂复用高原结构并调整冰色，后续完整冰山岛再制作成套雪墙与冰港建筑。

冰锥与霜环各新增释放、命中声音，共 12 个变化，来自已有 CC0 授权素材的独立处理。原来已认可的配乐、刀剑与流星声音文件没有改写。样板配乐暂选已有森林曲目，环境声暂用风声；专属冰岛曲目留待完整章节。
