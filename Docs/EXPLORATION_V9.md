# 沙漠岛探索 V9 规则与验证

本版替换 V8 的路线按钮界面。V8 设计和测试记录保留作历史，不再描述当前默认规则。

## 地图与流程

三层分别为沙丘边缘（12 间）、断渠遗迹（13 间）、古渠核心（14 间）。每层从随机生长的四向连接图生成，可能有支路和环路。不是必须清空 39 间才能通关：玩家自行探索与回访。首两层的远端房间为守渠者，最后一层远端为风石守关者；战后亮起风纹阶梯，走近自动上下层。

门通道宽 1.7，进入战斗后封闭；清完全部波次才能离开。普通门不按 F，走进通道约一个单位自动换房，从对门内侧出现；过渡约 0.24 秒，有短暂冷却避免来回弹跳。过门和暂停冻结模拟时间，护盾、技能冷却、受伤时间不会重置。不同房间的怪物阵容、进度、武器掉落在本轮中保留；未完成的战斗不能通过正常路线离开。

M 地图只读。已访问房间显示类型及状态，相邻未知房间显示问号，其余房间隐藏。没有地图传送和路线选择按钮。

普通房前两层 2 波，第三层 3 波；每波 4 + 层索引 + 随机 0/1 名敌人。精英房 3–4 波并出现石卫，最多每波 6 名。波间约 1.1 秒休息，敌人落地前预警约 0.8 秒。探索计数引入砂蝎、枪卫、滚蓬、沙鹞，石卫作为精英／守渠者出现。三种最终 Boss 仍各有三种招式和低血量强化。

## 生存与成长

| 项目 | 当前规则 |
| --- | --- |
| 生命／护盾 | 6 / 4；先扣盾，溢出扣血，受伤约 0.8 秒无敌 |
| 护盾恢复 | 连续 5 秒无受伤后 1 点／秒，受伤重新计时 |
| 光能 | 上限 100，默认恢复 4／秒；击杀不直接返还 |
| 元气弹 L | 清 3 个不同战斗房后，在教学台按 F 学；24 伤害、20 光能、2.2 秒冷却、1.8 秒寿命、场上最多一颗；有限转向，失去目标后直飞 |
| 风之刃 U | 清 6 房或第一守渠者确保学习进度；22 风伤、20 光能、2.5 秒冷却、直线穿过至多两名不同敌人，不能穿墙 |
| 风波 I | 清 10 房或第二守渠者确保学习进度；30 光能、9 秒冷却；约 0.35 秒向外扩散至半径 2.3，消普通飞弹，1 秒内雷伤降低 30% |
| 风石 | 最终 Boss 后风刃伤害变 26，风波冷却变 8 秒；仍需已学会技能 |
| 元素关系 | 风→雷 ×1.3、雷→风 ×0.85；其他关系为 ×1，后续扩展 |
| 破势 | 雷敌人受 3 次风命中后可打断蓄力；之后 6 秒不能重复积累 |

学习次数只统计不同战斗房清理，回访不累计。教学台可在之后已清理的房间再次出现，直到玩家学习；同一时刻只教一项。风波不删除地面攻击预警与落雷判定。武器元素只影响该武器的普攻，不改变玩家元素或技能元素。光能不足时不能释放对应攻击。

恢复房一次恢复 2 生命并补满光能；旧渠事件一次恢复 1 生命与 20 光能。奖励房需靠近补给按 F，在回血 2、近战伤害 +2、回能 +1／秒（最高 8）并回能 30 中选一。普通清房无自动补血补能。

| --- | --- | --- | --- |

| 旧木法杖 | 光 10 | 0.65 秒 | 5 |
| 风纹剑 | 风 16 | 0.32 秒 | 0 |
| 裂岩重剑 | 物理 25 | 0.65 秒 | 0 |

初始只有短剑；第一次拾取填入第二栏。两栏都满时替换当前武器，原武器落在脚边。H 切换，F 优先学习附近教学台，其次拾武器，再开补给。奖励房、守渠者和部分战斗房掉落武器；掉落数据保留在所属房间。多把武器共用四种基础造型，风／重剑变体通过颜色、长度和参数区分。

人物身体不再烘焙剑刃，武器单独绘制并跟随动作握持点。四向走路各六帧，左侧复用右侧镜像以保留腿部交替；攻击有身体随动。当前是分层帧动画，尚非骨骼动画系统。

## 测试入口与复跑

- `Assets/Scenes/NakiTest.unity`：完整沙漠旅程。
- `Assets/Scenes/NakiBossPractice.unity`：随机最终 Boss，三技能与两武器已开放。
- `Assets/Scenes/NakiElementTrial.unity`：雷属性巨像试炼，复用巨像造型和招式；普攻／范围打击标记雷属性，便于比较风刃克制与风波减伤。不是完整雷岛。

运行验证：在**隔离工程副本**把 `Validation/ExplorationV9/ExplorationSmoke.cs` 放到 `Assets/Tests/Editor`，执行 Unity `-executeMethod NakiExplorationSmoke.Run`。脚本会切 Play、改动测试状态并退出编辑器；输出路径常量默认指向本机仓库，换机器先修改。`VisualSmoke.cs` 使用真实 Game View 绘制与截图；同样只在隔离副本运行。报告和检查证据保存在同目录，运行截图存于被忽略的 runtime 目录，精选画面会另存 Art。

测试不能替代手感验收：重点体验剑与弓／杖的价值、护盾恢复是否够用、连续 3 层的疲劳感、风技能学习时机，以及门口移动与受击反馈。
