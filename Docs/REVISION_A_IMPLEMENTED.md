# 六岛规划第一阶段：暗系加强、章节身份、交互物修正

本轮完成的是整体计划 A/B 的基础改造及交互修正。冰山、烈焰、府邸仍未制作可玩场景，不能把六岛顺序表理解为已经完成六座岛。

## 暗系数值已实装

- 新暗路线初始 6 点，上限 100；现有存档的储量保留。
- 普通有灵敌人击杀 +2，精英或符合资格的 Boss +3；同一敌人只结算一次。召唤物、石像、机械、植物机关、剧情幸存的守护者不充能。
- 一次流星生成两颗追踪球，共消耗 1 点，每球基础伤害 15；施放前储量提供最多 20% 伤害加成，再计入所在章节的技能成长和目标防御。
- 冷却 1 秒，最多两组／四颗球同时存在。一颗先命中后，其所在组仍计数，不能利用半组弹体突破上限。
- 如果两颗球都被贴墙阻挡，既不扣费，也不进入冷却；至少发出一颗才完成一次施法。
- 主属性卡片和学习提示同步改为 1 点消耗。光技能、元素资源和已有音频保留原规则。

## 六岛身份和旧档

章节配置登记顺序：沙漠 1、雷雨高原 2、冰山 3、烈焰 4、青栖林海 5、大骑士府邸 6。已有场景布尔开关作为兼容适配器保留，本轮没有强行重写所有旧场景。

森林在画面中显示第五岛，其基础护盾上限 6、技能成长倍率 1.38；雷岛仍为护盾 5、倍率 1.15。成长由当前章节配置计算，不在读档时重复叠加。

已有森林 45 房与存档文件 woodland-chapter-v1.json 保留。新保存记录携带航线版本和岛序元信息，旧档缺少这些字段仍可读取，已清房间、解救状态、装备、资源不重置。

雷岛到森林的现有直达入口标记为第五岛试航，供继续测试已制作内容。冰岛、火岛完成后再接正式主线航路。

五元素基础倍率已统一：风克雷、雷克冰、冰克火、火克木、木克风，强克制 1.3，其余默认 1.0。提示显示实际元素名称，不再所有弱点都写“风克雷”。森林的植物、寄生组织弱火，普通动物不统一标为木弱点。新冰火技能及破甲、冷却地形等机制仍待对应章节制作。

## 解救采种人是开牢笼

朽木腹地的看守房间在战斗中就能看到锁着的铁笼和笼内人物。看守未清理时不能开笼；清房获得钥匙后，靠近笼门按 F 开锁，笼门换成打开状态，前方实体阻挡撤除，人物移动到笼外。之后 F 是与获救者交谈，不会再次结算救援。

营救仍使用原有存档中的获救标记，因此更新前已经救过的人不会重新被关进去。读档、回访、重建交互物时保持开门状态，也不会不断增加碰撞体。地图把该房标为牢笼／已获救，目标提示随救援结果更新。

其他森林交互改为对应物件：林册书架负责学习根刺，腐木与菌丝负责调查，孢种袋负责领悟孢种，种床负责栽种，码头木盒交还林册，船负责登船，路牌负责返程。沙漠与雷岛的学习点改为书册，观雨及部分返程位置使用路牌。

道具美术由内置 imagegen 生成，保存于 Assets/NakiPrototype/Resources/NakiArt/WorldPropsV1；素材与生成提示见 Art/WorldPropsV1/README.md。人物本轮沿用现有居民角色美术。

## 怎么测试

1. 停止 Play，等待 Unity 导入和编译。Tools → Naki Legend → Play → 1 Desert Adventure 可继续沙漠，选择暗路线的新旅程从 6 点开始；旧档不清空能量。
2. Tools → Naki Legend → Play → 5 Woodland Adventure 继续森林。去第二层看守牢笼，清房后靠近门按 F。已经获救的旧档会直接显示打开的笼门和笼外人物，不要求重打一遍。
3. Boss 练习现在位于 Tools → Naki Legend → Boss Practice，按岛序分组，练习不覆盖正式章节存档。
4. Tools → Naki Legend → World Route 查看已开放章节与待制作章节。
