# 暮钟岛场景与剧情修复 V4

本土终章暂不施工。本次修复范围为暮钟岛三层 45 房间，保留当前战斗数值、装备编号、任务位与存档格式。

## 场景与通行

- 移除断粮旧村复用的火焰岛岩洞避难所。专用灰石民居、医师诊所与粮仓只出现在对应房间；门楼和档案室不会再凭房间类型自动摆放同一栋避难所。
- 新增六件统一灰石、板岩、旧木风格的素材：民居、诊所、粮仓、门廊、档案桌、旧种盒。素材由内置 imagegen 生成，经色键去底和原生渲染检查后接入。
- 第一层卫长房间、第二层入口与掌印房间、第三层入口各保留一处跨层门廊。通用楼梯不再重复生成；房间边缘的普通门继续用于同层走动。
- 跨层提示直接读取航图层名：归功外庭、断粮旧村、无昼内庭。进入与返回共用同一套对应关系。
- 房屋仅以地面基座阻挡移动，屋顶、雨棚不扩大碰撞。居民站在门前可达的位置；反复交互不堆叠碰撞。
- 种盒互动显示真实种盒，档案、航海手记与求援信使用档案桌；居民不会代替物件充当交互图标。

## 引导和结局

修复后两层的引导始终返回第一层卫长的问题。任务目标依次为粮仓／守粮人、转运间／医师、封印档案、掌印机关、大骑士。跨层引导指向唯一门廊。

修复光之力分支中循环与 else 的绑定错误。光之力路线只出现尚未解开的王印，贤者之石路线正常出现一处抉择入口。读取选择前安全存档后仍能正确显示。

## 剧情文字

卫长谈话、旧村登场、粮药支线、封印档案、三处调查文本、掌印机关战后、大骑士战后及结尾文字重新梳理。

居民描述断粮、等药和前代勇者的变化；任务操作放在 HUD 和交互提示。三处调查分别提供航海手记、王印原令、旧村求援信，不再复制同一段解释。空甲里的声音明确称为残响。结局文案移除“尚待下一章”等开发状态说明。

## 验证与继续试玩

Unity 原生 348 项检查通过，另通过 C# 编译。验证涵盖全部房间的单一跨层入口、入口可达性、重复交互碰撞、层名与实际目的地、任务引导、证据对白差异、两种结局入口及旧档读写；三个房间另作原生截图检查。
