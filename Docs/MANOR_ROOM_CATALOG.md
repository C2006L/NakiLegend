## 断粮旧村与淬炼工坊

| 房间 | 类型 | 目标与交互 | 敌人与内容 |
| --- | --- | --- | --- |
| 2-01 旧村避难院 | 安全 | 与守粮人见面；得知城内有存粮，却禁止运输。 | 居民位于有门墙保护的区域 |
| 2-02 扣粮岗 | 战斗 | 清除堵住粮道的守军；放行后安全侧道承担运粮。 | 巡卫、锁链狱卒 |

| 2-05 药材储间 | 奖励 | 选择装备或药箱补给；额外故事不强制索取资源。 | 四选一补给 |
| 2-06 诊疗屋 | 安全 | 医师缇娅说明完整意志与战斗残响的差别。 | 医师与居民；战斗时院门关闭 |
| 2-07 锁链广场 | 精英 | 切断钩链造成的封路，避免站在收钩路径上。 | 精英狱卒、巡卫 |
| 2-08 药运走廊 | 战斗 | 打通诊疗屋的药物转运道路，安全后居民从侧门接走药箱。 | 弩手、狱卒 |
| 2-09 淬炼车间 | 战斗 | 击破运行中的人工容器；战后查看容器与源石的区别。 | 空甲傀儡、掌印执役 |
| 2-10 封印档案室 | 事件 | 用画像、佩剑编号和受封档案确认前代身份，播放画像 CG。 | 固定关键线索；前往机关的必经房 |
| 2-11 居民后巷 | 战斗 | 从高低断墙之间绕行，救出尚未进入避难院的工匠。 | 猎犬、巡卫 |
| 2-12 钟匠工棚 | 安全 | 伊芙解释远处钟声在同步控制甲胄；提供一次整备。 | 可重读关键规则，不能无限领取补给 |
| 2-13 账房暗格 | 奖励 | 探索支路获得装备，发现前代未寄出的家书。 | 普通补给与非必需往事 |
| 2-14 印痕回廊 | 精英 | 优先击倒执役，拆散护印与盾卫的组合。 | 精英执役、盾卫 |
| 2-15 掌印机关缄令者 | 首领 | 逐个破坏刻印臂，停止封锁命令；带走带封蜡的契约原令。 | 机关首领；一次专武奖励 |

| 房间 | 类型 | 目标与交互 | 敌人与内容 |

| 3-13 无昼长廊 | 战斗 | 在短时显形的回声与实体巡卫之间切换目标。 | 残誓回声、巡卫 |
| 3-14 回声长厅 | 战斗 | 观察回声显形与攻击的节奏，练习在窗口内集中输出。 | 回声、傀儡 |
| 3-15 暮钟大厅 | 首领 | 三阶段对战暗黑大骑士；战斗结束后进入明确的光暗收尾。 | 大骑士；战斗与结局奖励分开结算 |
