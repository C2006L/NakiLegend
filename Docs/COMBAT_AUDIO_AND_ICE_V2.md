## 修复

浮冰晶灵原本进入射程便停止移动，冰柱挡住它的射击，也挡住玩家自动瞄准。现在攻击需要无遮挡视线，受阻时沿障碍物角点绕行。导航同时考虑矮基座、高冰柱和阻挡行走的冰缝；不再只判断脚部位置。已重叠在高冰柱中的单位会恢复到最近安全位置，不扣血、不直接清怪。相同绕行用于冰岛守卫、猎犬、弓手和祭司。

第二岛结尾目标提示明确指向左侧码头。存档文件路径、房间编号及通关标记均保持。

## 雷电音效

本轮仅改雷标、跃电和雷电法杖的 15 个声音变体：去掉连续电流底噪，将单次放电限制在 28ms 内，叠加较低频的冲击和短破空声；施法音量低于命中音量。雷标真正落下仍在预警后 0.65 秒，此时才播放较重命中声。

参考 [Blizzard《暗黑破坏神 IV》音效设计说明](https://news.blizzard.com/en-gb/article/23731236/diablo-iv-quarterly-updateoctober-2021) 中关于录音加工、重复播放舒适度和战斗混音清晰度的方法。没有提取该游戏音频；原材料仍是已有 CC0 素材，出处见音效目录 credits.json。音乐、剑声及其他技能未改。

试听 `Art/CombatAudioV3/lightning-refined-preview.wav`：0 秒雷标释放，0.65 秒命中；2 秒跃电；4 秒开始雷杖三次；7 秒再演示雷标。技术检查不能代替实际听感评估。

# 战斗音效第三版与冰港地图扩充

本轮声音调整在所有岛屿生效，地图与敌人扩充落在第三岛冰港。已认可的配乐和刀剑声保留。

## 声音改了什么

原先不少技能由同一组魔法音经过较大变调得到，连续施放时尾音和尖锐音高变化会反复叠加。这版使用实录弓箭、挥动、电火花，以及授权的火焰、木石碰撞素材，重新剪辑和分层；不再加入长混响、反向音或显著八度变调。

| 声音 | 新处理 |
| --- | --- |
| 风刃、护身风波 | 短促破风与碰撞，风波稍宽，避免连续长嘶声 |
| 流星 | 低沉的短发射、石火碰撞；释放与命中分开，保留暗系辨识度 |
| 雷标、跃电、雷杖 | 使用 Tesla 电火花录音，雷标命中带较厚碰撞，跃电偏短脆，雷杖单独选择电击发射声 |
| 弓箭、弩 | 实录离弦与箭羽掠过，弩保留机械动作；快速收尾，压掉橡皮筋式长颤音 |
| 元气弹、根刺、孢种、冰锥、霜环 | 同步采用较短的风、木石和结晶反馈，区分释放与命中 |

十项技能 × 释放/命中 × 三个变化，加上弓、弩、雷杖各三个变化，共 **69 个短音效**，最长 0.27 秒。调整了技能播放增益，并继续使用现有音效通道上限，减少连发叠音。

运行时优先读取 `Assets/NakiPrototype/Resources/NakiCombatAudioV3/`。旧银行原文件没有改写，原配乐、剑击及其余已保留文件共 82 个，已做 SHA-256 对照。声音主观听感仍以实际试听为准。

## 冰港从三房扩展为五房

主路仍是码头 → 冰封回廊 → 裂冰甲兽。回廊新增北侧的 **覆雪货仓**、南侧的 **霜镜瞭台**，都是可选支路，各有三波战斗和一次性装备、元素结晶奖励。主回廊增加到四波，逐步组合近战、扑击和远程单位。

不强迫玩家先清支路才能打 Boss；已有 Boss 进度不会因为增加内容而重置。

### 新敌人

| 敌人 | 行为与应对 |
| --- | --- |
| 霜牙猎犬 | 56 生命；接近后预警，再沿锁定方向扑击。侧移躲开，利用其恢复时间反击 |
| 寒弓游猎者 | 64 生命；保持射击距离，预警后向旧方向发出两支冰箭；可用掩体挡箭，贴近可迫使其后退 |
| 刻霜祭司 | 96 生命、一片晶甲；预警旧落点，再生成持续 1.6 秒的危险霜纹。及时离开落点，优先打断/击倒施法者 |

原晶甲守卫、浮冰晶灵和裂冰甲兽保留，现在共有五类普通敌人及一位 Boss。猎犬和弓手属于有灵生物，可补充贤者之石；石制祭司不补充灵魂。

### 障碍物

新增覆雪货箱、冻桶、高冰柱、冰裂隙和漂木路障。货箱、冻桶、冰柱和漂木均阻挡通行与飞弹；脚部通行范围与整幅图片挡弹范围分别处理，避免打到上半部却穿过去。冰裂隙只阻挡地面通行，飞弹可以越过。

障碍物分布随房间用途变化：码头偏货物和漂木，货仓偏箱桶，瞭台偏冰柱和裂隙。门口、出生点和交互物附近保留通路。所有门到房间中部的绕行路径经过验证。

地图面板按实际房间坐标居中和缩放，新增负坐标支路不会跑到图例上。未知房间仍按探索显示，不直接给出可点击跳关选择。
