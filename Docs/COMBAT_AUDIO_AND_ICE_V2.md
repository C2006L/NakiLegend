# 战斗音效第三版与冰港地图扩充

本轮声音调整在所有岛屿生效，地图与敌人扩充落在第三岛冰港。已认可的配乐和刀剑声保留。

## 声音改了什么

原先不少技能由同一组魔法音经过较大变调得到，连续施放时尾音和尖锐音高变化会反复叠加。这版使用实录弓箭、挥动、电火花，以及授权的火焰、木石碰撞素材，重新剪辑和分层；不再加入长混响、反向音或显著八度变调。

| 声音 | 新处理 |
| --- | --- |
| 风刃、护身风波 | 短促破风与碰撞，风波稍宽，避免连续长嘶声 |
| 流星 | 低沉的短发射、石火碰撞；释放与命中分开，保留暗系辨识度 |
| 雷标、跃电、雷杖 | 使用 Tesla 电火花录音，雷标命中带较厚碰撞，跃电偏短脆，雷杖单独选择电击发射声 |
| 弓箭、弩 | 实录离弦与箭羽掠过，弩保留机械动作；快速收尾，压掉橡皮筋式长颤音 |
| 元气弹、根刺、孢种、冰锥、霜环 | 同步采用较短的风、木石和结晶反馈，区分释放与命中 |

十项技能 × 释放/命中 × 三个变化，加上弓、弩、雷杖各三个变化，共 **69 个短音效**，最长 0.27 秒。调整了技能播放增益，并继续使用现有音效通道上限，减少连发叠音。

运行时优先读取 `Assets/NakiPrototype/Resources/NakiCombatAudioV3/`。旧银行原文件没有改写，原配乐、剑击及其余已保留文件共 82 个，已做 SHA-256 对照。声音主观听感仍以实际试听为准。

### 不开游戏先试听

`Art/CombatAudioV3/combat-audio-v3-preview.wav`：

- 0–2 秒：弓箭。
- 2–4 秒：风刃。
- 4–6 秒：流星释放。
- 6–8 秒：雷标命中。
- 8–10 秒：跃电释放。
- 10–12 秒：霜环。
- 12–17 秒：模拟连发叠加。

每组前两次为不同变化。试听文件使用新音效，未添加旁白或配乐；游戏内 F10 的音量偏好继续保留。

## 冰港从三房扩展为五房

主路仍是码头 → 冰封回廊 → 裂冰甲兽。回廊新增北侧的 **覆雪货仓**、南侧的 **霜镜瞭台**，都是可选支路，各有三波战斗和一次性装备、元素结晶奖励。主回廊增加到四波，逐步组合近战、扑击和远程单位。

不强迫玩家先清支路才能打 Boss；已有 Boss 进度不会因为增加内容而重置。

### 新敌人

| 敌人 | 行为与应对 |
| --- | --- |
| 霜牙猎犬 | 56 生命；接近后预警，再沿锁定方向扑击。侧移躲开，利用其恢复时间反击 |
| 寒弓游猎者 | 64 生命；保持射击距离，预警后向旧方向发出两支冰箭；可用掩体挡箭，贴近可迫使其后退 |
| 刻霜祭司 | 96 生命、一片晶甲；预警旧落点，再生成持续 1.6 秒的危险霜纹。及时离开落点，优先打断/击倒施法者 |

原晶甲守卫、浮冰晶灵和裂冰甲兽保留，现在共有五类普通敌人及一位 Boss。猎犬和弓手属于有灵生物，可补充贤者之石；石制祭司不补充灵魂。

### 障碍物

新增覆雪货箱、冻桶、高冰柱、冰裂隙和漂木路障。货箱、冻桶、冰柱和漂木均阻挡通行与飞弹；脚部通行范围与整幅图片挡弹范围分别处理，避免打到上半部却穿过去。冰裂隙只阻挡地面通行，飞弹可以越过。

障碍物分布随房间用途变化：码头偏货物和漂木，货仓偏箱桶，瞭台偏冰柱和裂隙。门口、出生点和交互物附近保留通路。所有门到房间中部的绕行路径经过验证。

地图面板按实际房间坐标居中和缩放，新增负坐标支路不会跑到图例上。未知房间仍按探索显示，不直接给出可点击跳关选择。

## 如何测试与继续旧档

1. 停止 Unity Play，等待编译完成。
2. **Tools → Naki Legend → Play → 3 Ice Harbor Sample**，点击 Play。
3. 已有冰港存档按 F 继续；在回廊向北进入货仓、向南进入瞭台。M 查看探索地图。
4. 只测试技能/Boss，可用 **Boss Practice → 3 Ice Beast**，T 配置 U / I。

存档文件仍是 `Application.persistentDataPath/NakiLegend/ice-sample-v1.json`。旧 `ice-s1-v1` 三房数据在读取时升级到五房 `ice-s2-v1`，保留前三房已清理状态、Boss、剧情、已学技能、冷却、资源和装备。新支路初始未清理；首次写入升级结果时，旧主文件成为 `.bak`。不需要删档或重打前两座岛，也不要求已经打过的冰港 Boss 再打一遍。

地图扩展范围是冰港探索样板，尚未代替完整冰山岛三层。新单位当前仍采用独立精灵、朝向、移动起伏、蓄力与动作特效，完整多帧动画留待后续制作。

## 素材来源与构建

声音风格参考短促、清晰的动作游戏战斗反馈，没有使用《元气骑士》的音频文件。

- [Still North Media / Ben Jaszczak & Brian Nelson — Medieval Weapon Textures](https://opengameart.org/content/medieval-sound-effects-weapon-textures)，CC0：实录弓、弩、箭羽、挥动。
- [BMacZero / Brian MacIntosh — Electricity Sound Effects](https://opengameart.org/content/electricity-sound-effects-0)，CC0：Tesla 电火花。
- [rubberduck — 80 CC0 RPG SFX](https://opengameart.org/content/80-cc0-rpg-sfx)，CC0：风刃、火焰、木石及结晶处理素材。

每个新文件的组成、时长和来源哈希见新音效银行的 `credits.json`。`Tools/fetch_combat_audio_v3.py` 缓存来源，`Tools/build_combat_audio_v3.py` 构建新银行和试听，源包放在被 Git 忽略的 `References/CombatAudioV3/`。本机工具依赖放在项目外层的工具目录，不随运行包发布。

新美术由内置 imagegen 生成，成品与提示词见 `Art/IceSampleExpansion/README.md`。
