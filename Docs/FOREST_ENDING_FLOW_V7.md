# 青栖林海结局流程修正

森林受到寄生菌丝驱动而过度生长，老树无法休眠，种根得不到养分。救回采种人、记录菌丝与空果壳等线索后，前往树冠旧庭解除古树寄生并取回木石；返回第一层旧叶种床栽种，再回雾岸码头交还林册，播放《旧叶落处，新芽有声》。完成 CG 后才标记本岛尾声完成。

第二层原有的“幼芽旧床”是调查线索，曾与结局共用萌芽图片，造成提前完成故事的错觉。本轮改为“休眠种根”，显示尚未萌发的种床，台词说明仍有生机但被菌丝夺走养分。它不会触发栽种或结局。

栽种交互要求最终首领房已清理、木石已取回、玩家位于第一层旧叶种床。CG 完成同样检查前置条件。旧存档若最终首领房尚未清理，则清除错误的取石、栽种与结局标志；正常完成的进度保留，不清除装备或房间探索。

最终首领房的占位箭头木牌换成树洞返回入口。所有运行时遗留“木岛”提示统一为青栖林海。

独立 Unity 流程验证通过 11 项检查，涵盖第二层无结局幼芽图、提前栽种与 CG 被阻止、正常栽种→码头 CG→完成顺序、提示名称及返回入口。脚本已同步实际 Unity 工程。停止播放、等待编译、F9 继续即可。
