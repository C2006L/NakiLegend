# 两座岛游玩指南（V18）

目前是两座岛，每座岛各有三层；木岛只有设计文档，尚未成为可玩章节。

## 打开游戏

Unity 项目位置：`D:/NakiLegend/UnityPrototype/Assets/NakiPrototype/NakiLegend`。
先点击顶部蓝色播放按钮停止运行，等编译结束，再打开下面的 Tools 菜单，最后点击播放按钮。菜单名称虽然有 Play，但作用是打开场景，不会自动开始游戏。

| Tools → Naki Legend 中的菜单 | 用途 |
| --- | --- |
| Play → 1 Desert Adventure | 正式沙漠岛主线，从这里开始完整冒险；有存档时恢复沙漠安全点 |
| Play → 2 Thunder Plateau Adventure | 正式第二岛雷雨高原；有存档时自动继续第二岛，无存档时显示测试起点配置 |
| Play → 3 Thunder Boss Practice | 第二岛 Boss 独立练习，不覆盖正式第二岛存档；N 打开配置可切换三个 Boss |
| Play → 4 Desert Boss Practice | 沙漠 Boss 独立练习，不等同于主线通关，不播放正式甘泽结局 |
| Open Thunder Plateau Prototype | 早期两个房间的机制样板，不是完整第二岛，存档独立 |
| Open Old Canal Gatehouse | 独立水渠样板，不是正式沙漠通关后的续档入口 |
| Reimport generated artwork | 开发用图片导入设置修复，不是关卡入口，正常游玩不用点 |

## 正式路线

1. 沙漠岛：观看出航/登岛说明，选择战斗专长与光暗方向，沿打开的实体石门探索。M 查看路线，靠近人物、碑刻、机关、奖励按 F。
2. 依次探索沙丘边缘、断渠遗迹、古渠核心三层。在旅程中学习光/暗主技能、风之刃、护身风波，拾取武器与元素补给。
3. 击败沙漠守关 Boss 后，进入归渠尾声。清理敌人、修复轮机、开启总闸，完成水道工作后到瞭望处，才播放甘泽 CG。打败 Boss 本身不直接结束沙漠故事。
4. 完成尾声后，在瞭望区域靠近前往高原的风铃/登船交互点按 F。首次出航携带装备、光暗方向、专长和已学技能进入第二岛；如果已有第二岛存档，则优先恢复那个存档。
5. 第二岛依次探索雨中草坡、引雷遗址、雷鸣圣所。清理房间后复位东西引雷节点，寻找巡路员，并在碑刻处学习雷技能。T 整理 U/I 两个元素技能槽。
6. 击败巡雷巨鹿、回收雷石后，使用山路风铃返回灯棚，与灯匠交互完成归人尾声。之后可以回访支路，或在入口交互返回沙漠存档。

正式岛屿之间各自保留安全点。返回沙漠恢复的是沙漠存档，不是把第二岛所有状态反向覆盖过去。

## 本轮职业版本

选择界面使用 A/D 切换、F 确认，也可点击卡片。职业独立于光暗方向，不限制装备。

- 战士：K 保留闪避保护，并沿实际移动路径对碰到的目标造成 12 物理伤害。一次冲撞对同一目标仅一次；普通敌人轻微击退，Boss 不被击退，也不强制打断大招。墙体阻挡仍有效。
- 法师：元素消耗降低 15%，光之力与暗之力不打折。若第二武器栏空着，补发旧木法杖，短剑保留。
- 弓箭手：弓类散射降低 50%，射速提高 10%。若第二武器栏空着，补发猎沙短弓，短剑保留。
- 切武器不会取消已有攻击冷却。旅人短剑普通攻击仍零消耗。

这是专长第一版，尚未加入蓄力 J、战士招架、专长分支树或训练师转职。

旧档新增职业字段默认为未选择，继续游戏后补选，不清空装备或关卡。第一次补选后，在安全房间按 F5 保存一次。完整故事开局目前是在登岛介绍后选择专长，还没有独立可走动的王城训练场。

## 落雷怎么躲

敌方落雷：橙色固定外圈表示伤害范围，金色内圈向中心收缩。普通预警 0.9 秒，Boss 不同落雷有不同延迟，每个圈独立计时。圆圈出现后位置固定。

内圈收完时，白蓝色分叉电弧落地，地面闪光，**只在这一瞬间判断一次伤害**。外圈半径与判定同为 1.1 世界单位，按角色脚底位置判定。闪光消散不再造成后续伤害。己方雷标仍用冷蓝色，避免与敌方危险区混淆。

## 不想重新打一遍

直接打开 Play → 2 Thunder Plateau Adventure，播放后继续第二岛存档。F9 可以手动恢复；清房、完成机关和 Boss 后会自动保存，F5 可在安全房间再保存一次。

战斗中不存半波敌人，返回最近安全房间是预期行为。Boss 练习不记录主线通关。不必为测试落雷重打一整岛：使用 Play → 3 Thunder Boss Practice，N 选择引雷石卫长或巡雷巨鹿即可。

新职业字段兼容旧档，但此前已经被覆盖、删除的存档无法凭空恢复。第二岛明确确认新旅程时，会将原存档留为时间戳历史副本。
