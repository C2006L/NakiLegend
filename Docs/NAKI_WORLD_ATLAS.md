# Naki 全域航图与跨岛存档

本次把玩家可见的旧乘船入口统一接到全域航图，修复火岛码头按 F 直接载入冰岛的行为。五座已实现岛屿可自由选择；主线仍推荐沙漠 → 雷雨 → 冰岛 → 火岛 → 森林。府邸与王国只显示位置，尚未开放。

## 怎样试玩

退出 Unity Play，等待导入和编译，再运行原来的正式冒险场景，继续已有存档。

- **G**：打开全域航图。战斗中可查看，清房后才能出发。
- **M**：原有房间地图；其中也有“G 全域航图”按钮。
- 码头按 **F**：展开航图，不再直接前往另一座岛。
- 点击岛屿或用 A / D 选择，选择“继续当地安全点”或 1 / 2 / 3 层入口。
- 按 F 或“选择此行程”，阅读目的地后再确认出发。ESC 返回。

地图金色标记表示当前岛屿，右侧高亮当前层区，顶部显示当前房间。青绿色表示该岛尾声已完成。虚线只表示推荐顺序，不限制选择。

火岛完成后，可直接按 G → 青栖林海 → 继续当地安全点 → 确认出发。有森林存档会继续；没有则从雾岸码头开始。希望回访冰岛时自行选择霜潮群岛。

## 旅行规则

每座岛继续使用自己的 JSON 安全存档。离开前先保存当前岛；保存失败就留在原地。目的地已有存档则读取，不重新生成或重置其任务、已清房、掉落和天赋领取状态。损坏的目标文件先尝试备份，两份均不可读时回到来源安全点，不覆盖目标文件。

装备、职业、消耗品、已取得的天赋、生命和实际光暗／元素余量随玩家携带。护盾和元素按目的地允许的上限收束，不因往返刷新资源。首次进入未领取的休憩房，仍会触发该房原有的一次性休憩补给。已学冰火技能随行；各岛专有调查、营救与结尾条件留在对应存档内。跨岛时保留剩余技能冷却，并避免目的地已有结晶的生成时间落在存档时钟之后。

“继续当地安全点”保留当地的房间及安全落脚点。选择指定层区只抵达该层入口，不代打前层 Boss、不自动营救或学习任务技能，也不授予碎片、结尾和天赋。跳过主线后仍可能需要回到前层完成当地机关、调查与救援；航图会一直允许返回。

旧版内部航程函数暂保留用于旧存档回归测试，正式玩家的码头交互已统一进入航图。F5 / F9 仍保存和读取当前岛；若打开的是某岛独立测试场景，就继续该岛存档，可用 G 再选择其他岛。
