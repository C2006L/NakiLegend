# 首领攻击与收招节奏

本轮保留小怪血量降低 25%、首领降低 35% 的 V8 预算。每个首领约 7.5 秒进攻后，仍有完整 3.5 秒不主动攻击的输出窗口；强化集中在攻击阶段。

## 攻击阶段

- 所有可移动首领在短收招间隙继续追击、侧切或拉开距离：远于 5 单位靠近，近于 2.3 单位后撤，中距离侧移；遇障碍尝试转向。已在移动或冲锋时不叠加位移，蓄力预警与阶段切换时保持原行为。
- 招式内部零碎间隙压缩约 35%，保留蓄力预警时间；已有扇形齐射弹量增加约 20%，保持原覆盖角度，单颗投射物不重叠复制。普通小怪不会获得这一加成。
- 原有首领专属技能首次启动提前至约 1.6～2.0 秒，重复间隔改为 3.7～4.2 秒，避免刚要使用专属招式就进入输出窗口。
- 誓庭卫长冲锋掩护多一轮，环形弹后的连射多一轮，连射间隔由 0.24 秒改为 0.20 秒；增加机动，血量仍为 3,978。

## 输出窗口与弹速

窗口内停止主动攻击、清理残留敌弹和延迟招式，首领以约 0.85 单位／秒侧移或后撤；保持碰撞与导航，根植古树不强行滑动。控制状态期间不新增走位。窗口结束再恢复攻击组合，阶段召唤记录不重置。

前五岛保留 V8 首领战弹速降低 25%。卫长所在战斗进一步改为原始首领战倍率的 50%（相对 V8 再慢约三分之一），通过更多连发而非高速子弹制造压力。

每个首领／守关房在原布局基础上尝试增加一处符合岛屿风格的小掩体。多点候选，避开门、楼梯、机关与已有障碍，保留四周一单位间隔；行走和挡弹使用同一个小实体范围，不把树冠或透明边当墙。无安全位置时不强塞。
