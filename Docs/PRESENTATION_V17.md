# V17：视野、继续存档与攻击表现

本轮已实现于现有两岛；木岛仅为详细设计，入口尚未制作。

## 房间视野

状态栏整体缩小 20%，战斗视口在常用 16:9 分辨率下由屏幕高度约 72% 增至约 78%。减少镜头对墙外的边距，放大人物、地板和门；状态栏仍在战斗视口之外。行囊、对话沿用独立暂停界面。

## 存档说明

沙漠和第二岛使用独立存档。清理房间、机关、技能与 Boss 后在安全状态下自动保存；F5 手动保存，F9 恢复本岛安全点。战斗中回到最近清理的房间，不记录半波战斗。

打开正式雷雨高原场景后，有效档现在自动继续；N 配置页的 F 也优先继续。另起旅程需要明确确认，原主档先保留带时间戳的 `.previous` 副本。已击败的巨鹿和尾声状态写入存档，不因更新波次而重置；HUD 的保存状态会注明楼层、房间与是否已通关。

打开沙漠场景仍读取沙漠进度。继续第二岛请先停止 Play，用 Tools → Naki Legend → Play → 2 Thunder Plateau Adventure，再 Play。Boss 练习与正式旅程不同，练习不保存通关记录。

这次同步不会修改玩家现有 JSON。未在本次环境定位到用户实际的持久存档，因此不能声称已检查了用户那份档的具体通关状态。若曾主动开始新旅程，F9 只能读取当前主档；历史版本仍可能在 `.bak`，本轮后重开另存 `.previous`，不自动伪造通关。

## 攻击与技能

长矛改为前刺伸出、收回，命中采用狭窄直线，枪芒使用细直线；剑保留扇形斩光。弩使用更短更细的弩矢、短尾迹与持械后坐，弓使用较长箭身。已有手部动画仍使用现有帧图，此轮没有制作新的人物逐帧美术。

光球为暖金尾迹，暗流星为紫色短尾，风刃为薄青色尾流，跃电为细蓝光，雷标生效时有短促落雷与小范围闪光。特效复用引擎几何和已有素材，随弹体销毁、按原时间淡出；技能耗能、CD、伤害与锁敌规则沿用前版。
