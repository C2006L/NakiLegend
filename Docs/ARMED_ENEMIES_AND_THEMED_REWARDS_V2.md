# 武器对应攻击、同岛元素奖励与首领特效 V2

本轮把小怪的移动职责与攻击武器分开。守点、侧移、拦截等行为继续生效，攻击选择同时考虑怪物的形象、武器和距离。普通远程射击继续没有地面弹道预测线。

## 小怪攻击

| 怪物 | 现在的攻击与表现 |
| --- | --- |
| 断渠枪卫、锻火枪卫 | 约 3.4 单位内准备长枪穿刺，有短距离前踏、可见枪身和实际直线接触判定；远处发射一枚枪形元素弹。锻火枪卫使用火元素 |
| 巡雷枪卫 | 近处穿刺、中距离可锁向持枪突进，远处发射雷属性枪芒 |
| 灰砂短刃客 | 追近后前踏、挥出短刃弧光，身体有短暂挥斩倾角；只结算近战接触，不再受“狙击／守点”等职责的通用射击分支影响 |
| 晶甲守卫、雪壳蟹、裂壳熔蟹 | 近处斧／钳挥击，较远时锁向冲扑，不再发射不符合形象的通用散弹 |
| 寒弓游猎者、逐风沙鹞 | 保留箭形双射，而非圆形魔法球 |
| 炉鳞蜥 | 三枚火团扇射 |
| 煤袋投手、远距枯井石卫等炮击单位 | 抛出可见的弧线煤团／石弹，固定落点保留提示；只在落地时造成范围伤害 |

近战每次动作最多伤害同一玩家一次，攻击方向在动作期间锁定；控制效果可以打断，掩体继续阻挡伤害。短刃客之前已有近战判定，但只用一条短亮痕表现，容易被混在身旁的射击单位误导。本次补了明确挥斩与短距离前踏。

## 精英和装备箱

- 移除章节精英共用的固定编号掉落，避免赤炉群岛掉出雷雨武器。
- 前五岛精英奖励按当地元素选择：鸣沙洲风、雷雨高原雷、霜潮群岛冰、赤炉群岛火、青栖林海木。优先玩家职业对应的近战／法杖／弓弩类别，再在符合条件的武器与变体中随机。
- 统一精英清场奖励，同一次清场不再由共用和岛屿分支重复发武器。章节精英同时掉落 35 点元素结晶。
- 普通装备箱仍提供近战、法杖、弓弩三个方向。至少两个是当地元素，第一项职业偏好装备必为当地元素；第三项有约 18% 的尝试机会替换成符合当前主属性路线和已到达岛屿范围的稀有武器。没有合适候选时仍给当地装备。稀有武器不会占掉职业偏好的元素保底。
- 老存档中未领取的箱子会修正不合适的跨岛元素选项；已领取记录、人物装备和地上旧物保持原样。

## 已通关火岛、没有火武器怎么办

无需重打一遍。通过 G 航图返回赤炉群岛第一层的黑砂码头。已完成火岛尾声、随身两栏及备用行囊都没有火属性武器时，码头会出现“领取炉匠的火器军械”箱子，靠近按 F 可在火近战、火法杖、火弓弩中选一件。

这是一次性补领，领取状态写入本岛存档，F9 或跨岛回访不会重复刷新。可以选择“稍后再领”保留机会。选定的武器会放在身旁，按 F 拾取、自选替换武器格，不会自动顶掉当前装备。若备用行囊已有火武器，可直接按 B 装备。

## Boss 特效

在原有十五位主首领专属招式上增加实物及元素表现：

- 牵引／锻链：连续链环与清晰链路，区别准备期和生效期。
- 持续火区：范围内有跳动火舌；冰区、孢床和涡心使用不同晶体、孢体及旋转图形。
- 双极雷场：可见电弧与电核。
- 石柱／晶脊：地面碎块与升起实体，维持原来的真实阻挡及到期移除。
- 回旋投掷：旋转石刃图形，区别普通圆形弹。
- 潮墙：增厚浪尖，两侧标明安全缺口边界。
- 熔壳：正面增加高对比甲片，绕侧后正常输出；保护状态与视觉有效期对齐。
- 施放专属技时有聚能表现；顶部首领栏持续显示当前招式及应对方法，例如“穿过缺口”“绕侧后反击”，不再只在起手瞬间显示通用文案。

场地危险在结束前淡出；死亡、打断或换房会清理对应图形与碰撞。普通子弹的地面预测线没有加回来。
