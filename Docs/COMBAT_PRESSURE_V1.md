# 五岛战斗难度与可选试炼更新

本轮已把敌人协同、提前增援、Boss 阶段、可破坏掩体和可选挑战接入现有五岛。原有角色、专武、天赋、元素克制与光暗剧情保留；大骑士府邸仍未开放。

## 如何试玩

退出 Unity Play，等待编译与图片导入后重新运行，继续原存档即可。已清房不会重新刷怪。更新后的难度用于接下来进入的未清房和独立 Boss 练习。

- 完整章节入口仍在 Tools → Naki Legend → Play → 2／3／4／5 对应岛屿的 Adventure。
- 想快速看后期变化，可打开 4 Fire Islands Adventure，从原安全存档继续；要单独比较首领，使用 Boss Practice 下的相应岛屿入口。练习仍不覆盖正式存档，也不发放正式专武奖励。
- 雷雨、冰岛、火岛、森林的补给房新增小型试炼祭台。靠近按 F 查看风险，再按 F 或点按钮主动开启；ESC 返回。它不消耗原补给箱，也不要求主线必须完成。已经领过普通箱子的旧房间，也可以回去参加一次试炼。
- 战斗结束后 Console 搜索 `[Naki Encounter]`，可看到用时、受击次数、受到伤害、击杀数量及技能组数。记录留在本机 Console 和本次运行的最近 24 条内存记录中，无网络上传。

## 敌人配合与增援

沿用各岛原生怪物种类，在普通／精英波次中组织额外角色：

| 角色 | 行为与应对 |
| --- | --- |
| 侧翼追击 | 移速略快，从侧面压近，逼迫改变站位 |
| 远程配合 | 与近战形成错时压力，避免所有单位同时起手 |
| 护阵者 | 约 0.9 秒可打断的蓄势后，给可见的附近普通同伴短时减伤，并回复少量生命；不会给 Boss 治疗 |
| 狙击手 | 约 0.85 秒瞄准线后释放三颗高速窄角弹，射线被掩体阻挡 |
| 盾阵单位 | 正面普通弹伤害降至 40%；穿透弹与风属性保留 80%，侧后方和近战不受这项抵挡 |

雷岛开始，每波追加两个角色单位，替换旧版仅追加一个近战的规则；后期原波次人数较多时，净增通常约 15%～25%。沙漠前三场保留学习空间。

波次剩两名敌人且已交战至少 7 秒，或该波持续 18 秒时，会先预告，再提前进入下一波。当前仍有待入场单位时不会继续叠新波。实际非机关战斗单位上限为沙漠 7、雷／冰 9、火／森林 10；达到上限后援军等待释放。

出生点仍避开通道、门口和实体掩体。玩家走入预定出生点时，援军会换到安全位置并重新给出短预警，不会直接出现在脚下。

普通敌人缩短约 15% 的攻击后等待，保留原招式预警长度；进阶追击单位略提速。多数角色同时起手的数量也受调度限制。

## Boss 阶段与战斗时长

70% 血量进入强化阶段，原二阶段招式更早开始；35% 血量进入决战阶段，等待更短，追加错时扇射。雷岛起两个阶段各有一次预告增援，全部标记为召唤单位，不能刷贤者之石能量。

Boss 根据距离偏向不同招式，限制同一模式持续重复。部分已完成的攻击会接约 0.8 秒预告的后续扇射；后续弹幕保留实际墙体碰撞和路线空隙，Boss 死亡则取消。破甲、收招和原场景机关的反击窗口保留。

原版生命值是按较早的单弹武器设置的；现在的三／五弹、专武和暗能成长会过快跳过阶段。因此同步重新校准首领承受能力，前两层守关者也有最低战斗生命。普通怪生命只做较温和的分岛上调。

保留首领首次跨过三分之一血量时掉落 40 元素结晶的规则，且每场只触发一次。

## 武器与技能的集中伤害

暗能继续无 100 上限，普通击杀 +2、精英 +3，流星仍为 1 暗能释放五颗、每颗首击基础伤害 20，保留储量增益和三组并存限制。

同一组法杖或主属性弹丸连续命中同一 Boss 时，依次结算 100%／80%／65%／50%／50% 伤害。换下一组重新从完整首击计算；不同普通目标不共享计数。这让多弹清群与专武仍有价值，同时控制近距离集中输出。

灰烬喷杖的基础弹伤乘 0.75，保留低耗、快速喷射和近射程定位。其余弓弩继续沿用此前的 2/3 伤害与蓄力规则；此次没有统一提高技能耗能或取消自动瞄准。

## 可破坏掩体

新增独立六件道具图像。完整石柱、自然岩块等原掩体仍可长期挡弹；追加的脆弱掩体具有实际生命、脚底碰撞与弹体碰撞。

| 道具 | 被破坏后的行为 |
| --- | --- |
| 木箱 | 破开后打通行走和射线 |
| 油桶 | 约 0.7 秒预警后爆炸，伤害附近敌人，也会伤到过近的玩家 |
| 冰晶 | 预警后释放冻裂冲击，伤敌、短暂减速；玩家需要离开范围 |
| 藤墙 | 可以打破，火伤更快烧开 |
| 破裂火矿 | 预警后爆裂，形成一次环境风险 |
| 试炼祭台 | 仅用于主动交互，不混为可破坏补给箱 |

掩体优先避开出入口、任务点和已有实体。被破坏的状态写入房间存档，回房／读档不会凭空重新堵路。子弹先命中敌人时，不会同时打碎它身后的箱子。

## 可选试炼与存档

祭台明确告知两轮增援、暂时锁门与奖励。接受后才开始战斗；胜利获得一把当前已解锁阶段的武器变体和一份元素药剂，原补给箱仍可领取。奖励、挑战完成状态和掉落都随安全存档保存，不可重复领奖。

开启前尝试保存当前安全状态。挑战中不会覆盖安全档；失败按 R／F9 回上一个安全点。旧存档没有新增字段时，按“未挑战、未破坏掩体”读取，不删除已清房和装备。

## 验证与难度测量

完整检查见 Validation/PressureV1/runtime/smoke-result.txt。原生 Unity 2022.3.62f3 回归覆盖已有五岛剧情／CG／天赋／存档、角色与掉落，以及新的增援上限、护阵与盾阵实际受伤、狙击预警、阶段增援一次性、连招伤害、掩体碰撞、试炼奖励及落盘。

额外使用固定配置运行真正的敌人 AI、弹体、护盾、回能和技能循环，输出 combat-probes.csv。固定场景为火岛赤潮熔龟、战士专长、旧木法杖，原地持续 J／L，不使用闪避、药剂或换装：

| 测试条件 | 结果 |
| --- | --- |
| 300 暗能，正常受伤 | 约 24 秒倒下，Boss 仍约有 3295 生命 |
| 同一暗配置，关闭受伤，只测持续输出 | 约 40 秒击败 Boss |
| 光路线，关闭受伤，只测持续输出与自然回能 | 约 103 秒击败 Boss |

这些是固定操作的诊断数据，不是所有装备的通关时长，也不是对真人玩家难度的保证。稀有专武、元素克制、天赋及主动走位会改变结果。下一轮可以根据你实玩的受击和耗时继续调校。
