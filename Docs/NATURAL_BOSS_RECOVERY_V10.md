# 自然收招与小怪独立行动

本轮替代 V8/V9 的强制清场窗口处理，保留当前血量、攻击阶段机动、减速后的弹速和首领房掩体。

- 约 7.5 秒进攻段结束时，首领停止启动下一套招式，等待当前蓄力、冲锋、阶段过渡和已排定的连续齐射完成，再开始完整 3.5 秒收招。卫长已排定的连射、森林后续齐射和熔龟延迟齐射均不会被截断。
- 已发出的子弹不回收、不重置生命时间；已布置的落雷、爆炸与控场区域按原时序自然结束。场景切换与敌人死亡的正常清理保持。
- 收招期间首领继续缓慢侧移或后撤，不开启新招式；在途弹幕仍能命中玩家，因此进入窗口初期仍需留意上一招的尾弹。
- 小怪与援军完全独立，不跟随首领暂停，不清除它们的蓄力，也不禁止它们发射子弹。移除窗口内全局免伤。

隔离 Unity 测试通过 77 项检查：六岛的蓄力不被截断、子弹与延迟攻击保留、小怪蓄力与发弹独立、残留攻击可造成伤害、首领收招走位与时长，以及卫长两轮真实连射结束后才进入收招。
