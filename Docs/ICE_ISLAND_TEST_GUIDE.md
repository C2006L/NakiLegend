# 第三岛集中测试

本轮集中测试入口：停止 Play、等待编译，Tools → Naki Legend → Play → 3 Frost Tide Adventure，Play 后 F 继续已有存档。旧 3/5 房冰港进度会自动迁移，已清房、甲兽、技能与装备保留，不用重打。F5 手动保存（须安全），F9 当前岛读档；不要把 N 新旅程、R 重试当成继续。

建议按顺序验证：

1. 进港后沿门道边缘进入下一房，四方向不必站中线；门锁/未清房时不能通过。船在水中，岸上能登船，旧位置不应让玩家困在水里。
2. 甲兽已打过的存档，到原甲兽房读取记录后走石阶去冰峡。T 调整技能，重新阅读记录不改掉已选的 U/I。
3. 冰峡寻找受困营地，靠近实际绞盘按 F，打开营门、铺下撤离踏板；救援后重复交谈应是完成后的话。
4. 霜镜 Boss 半血生成两面镜子。普通武器能击碎，雷更有效；方向预警锁定后不追着玩家转，击碎会取消待发射攻击，全碎给反击窗口。
5. 最终 Boss 半血可用两侧绞盘。靠近 F 短按即可，每侧仅一次；清除敌弹并短时暴露核心，不会提前完成战后修闸。
6. Boss 后去回流闸室。先修一侧后 F5 保存，退出 Play 再 F 继续；应保留该侧状态。修第二侧能看到流水，开总闸返回码头，点归航灯后播放《潮声穿过长夜》。战胜 Boss 不能直接跳 CG。
7. CG 后读档应保留通关，守塔人不应再要求你首次救人；重温 CG 的入口明确标为重温。护盾上限依前两位 Boss 从 5 到 6、7，多次读档不累加。

只试 Boss：Tools → Naki Legend → Boss Practice → 3 Ice Beast / 3 Frost Mirror / 3 Tide Guardian。练习独立，不覆盖正式进度。要看后半段机制需要把 Boss 打到半血。

自动验证覆盖房间出口可达、整条剧情链、任务中间保存/恢复、旧样板迁移、重复交互、冰镜与绞盘、弹幕预警与主属性分离。真人测试重点是手感、难度、声音、提示易读程度。第三岛已达到集中试玩状态；新敌人多帧动画、武器独立原画等仍属于后续美术精修，不应把当前基本表现误认为全部正式美术已经完工。

本轮新增：弓弩按住 J 蓄力、松开射击；轻点快射，满蓄伤害弓 3 倍、弩 3.5 倍，蓄力射击额外 1 元素。各岛使用对应楼梯素材。救援/修闸时可观察短手轮转动反馈。详见 [操作说明](BOW_CHARGE_AND_ISLAND_STAIRS.md)。
