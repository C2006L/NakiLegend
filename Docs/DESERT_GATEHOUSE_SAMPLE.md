# 旧渠闸室可玩样板规格

状态：制作规格，尚未实现。此样板用于验证 [沙漠第一章设计](DESERT_CHAPTER_DESIGN.md) 的探索、战斗、事件、奖励与环境变化。运行版本保持 V12，下一步先在独立测试场景接入固定样板。

独立样板把 T03 的战斗检验与 T10 的 E02 修闸流程合在同一测试房里，方便一次走完联调。正式 39 房版本按章节表分别配置 T03 战斗和 T10 安全事件；样板场景不额外加入岛屿房数，E02 在一轮里只分配一次。

## 玩家经历

少年从南侧进入，先看到北侧可继续探索的石门，以及东侧一条被检修栅门封住的支路。沙石卡着中央偏北的手轮。玩家清完两波敌人后，可以直接从北门继续，也可以修好手轮、领取一次奖励，再沿新捷径回到已探索的安全房间。

这个房间的修理永远可选；不要求持有风武器、花光元素之力、解答方向谜题或重复杀怪刷资源。剧情对白不超过三次 F，观察与操作由现场道具承担。

## 固定布局

逻辑地面范围为宽 16 × 高 9 世界单位，坐标中心为原点。边界 x = ±8，y = ±4.5。以下是首个南进北出的固定版本；门位轮换与图连接在样板合格后制作。

```text
                         北门 通向后续探索
                 ┌─────────┄┄─────────┐
                 │      手轮与闸槽     │
                 │  沙堆A      沙堆B   │
                 │                    │
                 │  实心柱    实心柱  ╪ 东侧检修栅门
                 │                    │  通往可选捷径
                 │    分散敌人预警区  │
                 │                    │
                 │      入口缓冲区    │
                 └─────────┄┄─────────┘
                         南门 来路
```

| 对象 | 位置或范围 | 移动与弹丸规则 |
| --- | --- | --- |
| 南入口 | 门中心 (0, -4.5)，到达 (0, -2.6) | 沿用 V12 安全落点和进入保护；入口通道禁放障碍与敌人 |
| 北出口 | 门中心 (0, 4.5) | 战斗锁清除后通行，手轮和沙堆不占通道 |
| 东检修口 | 门中心 (8, 0) | 未修时由真实栅门阻挡；修理后满足两端安全条件才开放 |
| 左柱 | 地面锚点 (-3.3, 0) | 使用现有石柱移动脚印与全柱弹丸遮挡，不另造可穿柱规则 |
| 右柱 | 地面锚点 (3.3, 0) | 同左柱，两柱间保留可转身和绕行空间 |
| 手轮 | (-2.6, 2.7) | 交互半径 1.3；位于北门保留区之外，前方有可站立区 |
| 沙堆 A / B | (-4.4, 2.4) / (2.4, 2.3) | 作为交互物而非堵死门的障碍；各按 F 清一次 |
| 干渠 | y = 0.9 到 1.5 的浅槽 | 首批不阻挡移动；少量水恢复后不改变可行走范围 |
| 奖励位置 | 手轮前方最近安全点 | 完成修理后只创建一次；满元素时留结晶，回访仍在 |

房间边界、门口保留区和柱子碰撞共享同一份布局配置。行走通道目标净宽至少 2.4 单位，局部小段不可低于 1.6；门洞沿用 V12 约 2.3 的宽度。所有交互点至少保留一处半径 0.34 的安全站位和通往出口的路线。

## 两波战斗

首个制作阶段使用现有敌人、数值和预警系统。样板人数用于固定复现，与正式关卡的动态难度分开；试玩反馈后再调。

| 波次 | 敌人 | 落点示例 | 目的 |
| --- | --- | --- | --- |
| 第 1 波 | 2 砂蝎 + 2 枪卫 | (-5,1.8)、(4,-2.6)、(-4,-0.9)、(5.2,2.8) | 近战逼位与直刺，练习利用柱子转向 |
| 第 2 波 | 2 砂蝎 + 1 枪卫 + 1 沙鹞 | 两侧与北侧分散落点 | 在可见的远程前摇下选择接近、风刃或挡弹 |

所有落点执行 V12 的安全检查与地面预警，避开玩家、入口、实心柱、交互站位和待开放的门；距离不够就延后或寻找另一个合法点。波次之间沿用现有间隔，不能在敌人刚死的一帧于玩家脚下直接生成下一只。

只产生普通敌人的标准结晶，不因作为样板而多加光之力。风刃有足够元素时可以使用；元素不足也能靠初始免费武器与闪避完成。清房记一次战斗进度，修闸不额外计一次。

## 事件状态

| 状态 | 条件与可做操作 | 离开再回来 |
| --- | --- | --- |
| 战斗中 | 普通门按战斗规则封闭，修理物可观察但不可操作 | 沿用正常战斗限制，不能借事件传送逃离 |
| 可修理 | 清房完成，北门与来路开放 | 保留未完成状态，可以直接跳过修理 |
| 清沙中 | 两处沙堆各自可交互；每处演出约 0.6 秒 | 已清的那处保持完成，另一处继续可交互 |
| 可转轮 | 两处沙堆均已清除 | 手轮保持可用；反复 F 不重复触发 |
| 演出中 | 确认转轮后提交修理结果；约 2 秒闸门演出 | Esc 结束演出并直接显示最终状态 |
| 已完成 | 手轮转动，捷径等待两端清理；奖励只登记一次 | 不再刷奖励；保留水位与机关状态 |

在选择与短演出中暂停战斗时间，避免护盾恢复、技能冷却或敌人计时被剧情停顿影响。普通清沙也可采用可取消的短交互；取消发生在提交前时不计完成。提交后演出被跳过仍需完整兑现状态，不得撤销已领物品后再领一次。

## 对话和奖励

首次检查手轮：

少年：“轮齿还在，沙把它卡住了。”

完成清沙：

少年：“等风把云带回来，这里也得先有路。”

开启小闸：

“检修通路已开启。元素之力 +20。”

修理本身消耗 0 光、0 暗、0 元素。奖励使用单独的事件结晶，价值 20：元素未满时允许吸收，已满时保留地面。创建奖励与已创建标记一次提交；吸收记录使用现有结晶持久规则。清房与修理不叠加一份泛用事件奖励，不另补生命或光之力。

营地回访可以有一句对白：“那只手轮，总算不是摆设了。”不要求 NPC 在每次进房重复追着玩家说话。

## 捷径与水流

检修口的目标是本层已生成的邻接可选房间，仍使用四向实体门与通道。生成样板时保留这条锁定边，原图中另有正常路线连接两端。捷径解锁前，从入口到下一层始终可达。

未修理时门框和关闭的青铜栅门可见，显示“被沙卡住的检修闸”。修好后，如果另一端仍在战斗，提示“检修闸已修复，另一侧尚不安全”，清理后自动允许通行。不会把玩家送入未清房的紧贴门柱位置。

总闸未解锁时槽内干燥；第二守渠者败退且本闸修复后，显示少量存水；风石回收并到达雨后状态，再显示持续但克制的流动。水流用分层贴图和简短循环表现，固定碰撞不随贴图抖动。

## 素材与实现清单

首批制作独立手轮、闸门开 / 关、两种沙堆状态、浅槽干 / 湿两态和轮齿装饰，复用 V12 地面、门框、石柱、敌人和角色动作。短演出先使用角色靠近、物件转动与声音，人物专门的蹲下动作留待动作素材补齐后替换。

样板场景建议为 `NakiGatehouseSample.unity`，在现有工程中新增独立入口；后续实现时复用现有伤害、掉落、自动瞄准、背包与过门机制。事件、图连接与地面状态需要增加配置，不把样板写成一整套重复战斗脚本。

此阶段不需要新货币、流体模拟、跳跃、随机新 Boss、正式存档或额外技能按钮。样板通过后，把参数整理为房间配置，再接入三层房间池。

## 制作验收

| 检查 | 通过条件 |
| --- | --- |
| 南进北出与东口往返 | 所有实际到达点可移动；关闭的门不会把角色夹进柱子 |
| 角色无元素时清房 | 免费武器可以完成两波，掉落只补元素之力 |
| 自动瞄准与掩体 | 锁定合法目标，柱子持续挡弹；预警不与门锁混淆 |
| 先走、后修 | 清房后直接离开不被阻止；回访还能修理 |
| 清一堆后离开 | 已清沙堆不恢复，未清那堆仍可操作 |
| 快速连按与跳过 | 不重复开闸、不重复创建 20 元素结晶 |
| 元素已满 | 结晶留下，离开再回来仍在且不复制 |
| 捷径另一端未清 | 门保持安全锁定；正常主路仍能前进 |
| 开闸时位于门边 | 不在脚下新增碰撞，不强制移动玩家到障碍里 |
| 总闸前后回访 | 干槽、少量存水、雨后流动符合章节状态 |
| 背包与对话切换 | 输入只有一个界面接收，暂停时资源和战斗计时不前进 |
| 死亡、R 与 N | 当前轮内状态保留，重开清空本轮事件；新种子正常重新布局 |

以上是待实现的通过标准，本次只完成设计一致性检查，未声明新增运行测试通过。
