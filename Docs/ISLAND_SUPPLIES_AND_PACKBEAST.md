# 岛屿补给箱、火岛尾声与驮兽冲锋

本轮针对火岛装备箱、火岛收尾对白和冲锋抖动进行修改，同时把新的补给选择接入雷雨、冰岛、森林。正式场景和已有安全存档保留；停止 Play，等待编译，使用原章节入口继续即可。

## 补给箱

每箱提供三件装备和一份恢复补给，四选一。A/D 循环选择，F 领取，也可鼠标点击；ESC 返回不会消耗箱子。装备会放在角色旁边，再按 F 拾取，可替换任意携带或备用格。

- 火岛以炉匠、黑铁、熔晶为主题；冰岛用霜晶、白桦与银色构件；森林用藤木、竹节与新芽。
- 不按当前职业限制掉落：任何职业都可以选法杖、弓或弩，备用近战依然保留。
- 每层的候选装备按岛屿和深度提供，不再让火岛末层固定开出通用雷锤、风剑。雷雨保留自己的巡路装备体系。
- 恢复选项立即给予 **生命 +2、护盾 +2、元素之力 +35**，各自不超过上限；不改变光之力或贤者之石能量，不占武器格。
- 每箱只能领取一次，并写入本岛存档。新箱子不会先自动赠送一把职业武器、再额外领一次奖励。旧存档已经掉在地上的物品继续保留。
- 武器卡增加图标、元素、耗能与攻击方式，按真实行为区分蓄力穿透和普通直线射击。

## 乌龟之后为什么回到码头

截图仍是**第四岛·黑砂码头**，并非进入森林；问题之一是守岸人固定重播开场“先救避难所、再看熔蜥”的对白，让进度看起来倒退。

现在守岸人会根据避难所、熔蜥、撤离桥、火石、居民撤出及通关状态说不同内容。完整收尾顺序明确为：

1. 击败赤潮熔龟，留在庭院，取得火石。
2. 从东侧石门进入灰烬撤离道，清理后护送第一批居民。
3. 进入归岸石廊，清理后接应物资与最后的居民。互动后**留在石廊**，不立即传送回港。
4. 靠近旁边新出现的归岸路口，按 F 主动返回黑砂码头；对白说明走过冷却炉道、核对名单，并引导去公共炉灶。
5. 靠近公共炉灶按 F，播放《炉火重新升起》CG，结束后领取火岛天赋。
6. 选择留在火岛，或到码头单独确认前往森林。

如果原存档已经回到港口，不需要重打熔龟。护送全部完成便去点炉；尚未护送完成，对白和目标会指向剩余居民。旧档已完成的任务不会被清空。

## 火岛野猪／灰烬驮兽

按冲锋敌人的可躲避节奏重新实现：**蓄力预警 0.85 秒 → 沿锁定方向加速冲锋 → 停下恢复**。冲锋中不会不断转头追踪，也不会穿过玩家后突然翻面；正常结束停顿 1.1 秒，撞墙／掩体后停顿 1.35 秒，再留出攻击间隔。

旧行为的行走碰撞与弹体掩体判定不一致：冲锋先挤进掩体边缘，下一帧又被安全落点修正挪走，会出现反复抽动。本轮让冲锋按相同导航边界逐步检测，碰到障碍立即结束，不反复重定位。单次冲锋最多造成一次接触伤害。

设计方向参考《元气骑士》的野猪冲撞类型，项目中的时序、伤害和碰撞实现采用独立参数；[怪物资料参考](https://www.9game.cn/news/2097380.html)。本轮没有改动已认可的配乐和刀剑声音。
