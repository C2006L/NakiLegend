# 撤离桥头重新布置

撤离桥不再放在房间中央的完整地板上。排灰沟现在位于房间东部，沿南北方向一直通到墙边，沟槽覆盖地板，左右两岸有铁护栏，唯一的横向通路是铁索桥。

- 北门、南门和西门都在西岸，不会被沟槽封住；东门位于对岸。
- 绞盘固定在西岸、靠近桥头，界面提示与转轮动画使用同一实际位置。
- 未放桥时整条沟都不可行走。桥从西岸向东岸伸展，放下后只有桥面能通过，桥外仍是沟槽。
- 两名工匠在东岸等候。放桥后，工匠沿桥面到达西岸安全处；动作使用不受对白暂停影响的时间，不会因为正在读台词停在沟上。
- 回访和旧存档已经放桥时，直接显示完整桥面与西岸的工匠，不重复任务、奖励或撤离过程。

剧情仍然是救出阿铎 → 操作桥头绞盘、接通工坊撤离路线 → 挑战锻链巨匠 → 降温炉台回港。桥首先服务于工匠撤离，玩家不必为了找首领强行穿过桥再折返；出口箭头继续根据地图指向首领。

沿用原来的救援与放桥存档标记，不变更存档版本。读档位置如果落在新版沟槽或护栏上，沿用现有安全落点查找，不会把玩家留在障碍内部。

停止 Play、等待编译后继续旧档，回到“撤离桥头”即可查看新布局。已经放桥的档会看到完成状态。若要重试放桥过程，使用工坊测试配置，另起测试前会备份旧档；继续原进度应使用 F／F9，不选择另起。

使用已有环境图集组合场景，未新增生成图片或替换配乐。实际闭桥／开桥画面及碰撞、NPC 路线、存档回归见 `Validation/BridgeScene`。
