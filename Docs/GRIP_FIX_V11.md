# 武器握持修复 V11

问题：新版身体使用 256×256 的动作帧，武器仍依赖按方向推算的统一位置。走路／攻击时，手掌会移动到不同位置，统一偏移无法跟随，导致握柄悬空。左向攻击还存在世界瞄准角再次镜像的问题。

修复内容：

- 在保留的身体图集中逐帧标定手掌，按 130 PPU 和脚底基线 232 转成握持坐标。坐标数据见 `Art/GripV11/hand-anchors.json`。
- 身体帧、武器与手指遮挡共用同一个握持点，去掉另外添加的武器步行晃动和攻击位移。
- 左向步行沿用已修复的右向六帧镜像；手掌坐标和手指遮挡同步镜像。
- 校正短剑、长矛、弓、法杖的握持旋转轴；攻击方向直接使用世界瞄准角，避免左向攻击被重复翻转。
- 从身体图集以 Unity Sprite 裁切元数据提取 10×10 的手部遮挡片，保持原图不变；手部在握柄前方绘制，随人物缩放和受击色变化。
- 换房时重建遮挡对象，倒地时隐藏武器与遮挡。武器伤害、耗能、攻击间隔和技能规则未调整。

验证：八把武器、四朝向、待机／六帧步行／六帧攻击／施法／闪避／受击／倒地，在 0.75、1、1.25 三档人物缩放下检查；共 2305 个存活动作组合及倒地隐藏、换房清理、左向镜像和握持轴对齐。46 个直接标定的有效手掌坐标在原始 PNG 中均落在不透明棕色手套像素上，另六个左向行走握持点由右向镜像得到。

Unity 2022.3.62f3 / URP 的实际摄像机渲染已逐组核对，探索回归 69 项通过，最终运行时代码编译无警告。测试报告位于 `Validation/GripV11`；摄像机原始截图位于被忽略的 runtime 目录，精选核对图与左右行走动图保存在 `Art/GripV11`。
