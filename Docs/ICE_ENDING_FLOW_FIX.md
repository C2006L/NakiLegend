# 冰岛结尾、天赋与航程修复

正常流程为：寒潮守望者 → 救援已完成、清理两侧回流闸 → 开总闸返回冰港 → 点亮归航灯 → CG《潮声穿过长夜》 → 选择冰岛天赋 → 留在冰港 → 右侧码头确认前往赤炉群岛。

选天赋不会切换岛屿。返回雷雨高原是可选的返航路线，读取高原原有安全点，因此可能出现高原旧血量、旧装备与旧房间。这不是冰岛通关后的主线目的地。

## 本次修改

- 独立保存冰岛 CG 已完成标记 `iceCgSeen`。完整冰岛须完成 CG 才能领取天赋；旧五房间样板不发完整岛屿奖励。
- CG 与天赋关闭后，交互需要松开 F 并经过短暂间隔，防止确认动作误触场景内的船。
- 冰港返航与前往火岛都先显示目的地确认。F 需要松开后再次按下；ESC 留在冰港。打开界面的按键不能立即确认航程。
- 主线提示明确指向右侧码头与赤炉群岛；返航按钮明确写“上一岛”和“非主线”。
- 旧完整冰岛存档若已通关但缺少 CG 完成标记，下次读取会补播一次。保留已选天赋、装备和清房进度，不重复发奖励。补播完成后保存标记。
- 尚在播放 CG 的安全存档，重新读取仍显示 CG；已经看完的新存档不自动重复播放。归航灯仍可主动重温结尾。

## 当前进度如何继续

1. 停止 Play，等待脚本编译完成。
2. `Tools → Naki Legend → Play → 3 Frost Tide Adventure`，再次 Play。
3. 在冰岛起点界面按 F 继续本岛存档。不要选择另起旅程。
4. 已完成冰岛的旧存档会补播结尾 CG，已选天赋仍保留；无需重打首领。
5. 回到冰港后，前往右侧码头，按 F 并确认“前往下一座岛：赤炉群岛”。返回雷雨高原的选项仅用于回访。

如果读取的是尚未完成结尾任务的安全点，继续回流闸与点灯步骤即可；不会凭空把未完成任务改为通关。
